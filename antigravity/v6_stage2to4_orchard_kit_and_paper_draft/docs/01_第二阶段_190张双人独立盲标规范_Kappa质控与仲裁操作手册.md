## 二、四条不可逾越的盲标方法学红线

1. **仲裁前 100% 盲态原则**：标注人 1、标注人 2 及第三位仲裁人在完成全部标注与分歧裁定前，**绝不可查看** YOLOv8n、DINOv2、`G2_blur` 或 `C3` 的任何类别预测结果或置信度排序。本地盲标包已通过自动脚本执行字符串级断言校验（不含任何 `S1..S14` 预测值或概率浮点数）。
2. **“无法判断”独立编码原则**：凡因逆光高光、运动模糊、背面遮挡或症状早期非典型而无法仅凭肉眼确认的叶片/果实，**必须填写 `99`（`U99_无法判断_转不确定隔离`）**，严禁猜测或强行归入 `0..13` 类。导出 COCO 真值时，编码 `99` 自动标记为 `uncertain=True, category_id=-1`，由评测器单独统计隔离数，不污染正负类分母。
3. **外观症状与病原学确诊严格区分原则**：田间肉眼/照片标注仅表征**视觉外观疑似症状**。严禁将斑驳黄化（`2`）、红鼻果样（`3`）、叶脉黄化（`5`）或均匀黄化（`6`）表述为“确诊黄龙病（HLB）”；确诊必须依赖实时荧光定量 PCR（qPCR）实验室检测。
4. **几何框增删微调权限**：两位标注人可在 X-AnyLabeling / LabelMe 中打开 `x_anylabeling_class_blind_boxes/` 下的纯几何框 JSON：
   - 若候选框套中背景枝干/泥土等非柑橘器官伪框，填 `-1`（删除）；
   - 若画面主体病叶漏框，可手工补画矩形框并在对应 CSV 追加一行；质控脚本会自动按 `IoU >= 0.50` 一对一贪心匹配新增框。

## 三、标准症状编码表（`0..13` + `99` + `-1`）

| 填写编码 | 标准症状标签 | 判定要点与边界说明 |
| :---: | :--- | :--- |
| `0` | `S1_健康果实外观` | 果面光滑洁净、着色或青果色泽正常，无明显溃疡斑、木栓化或畸形 |
| `1` | `S2_健康叶片外观` | 叶色浓绿均匀、叶面平整，无病斑、无脉间或斑驳黄化 |
| `2` | `S3_斑驳黄化疑似症状(非确诊HLB)` | 叶片中脉两侧呈**不对称**黄绿相间斑驳（仅作外观疑似症状，非 PCR 确诊） |
| `3` | `S4_红鼻果疑似症状(非确诊HLB)` | 果实果蒂端异常着色或青果畸形偏小（外观疑似症状） |
| `4` | `S5_缺锌样脉间黄化症状` | 主侧脉保持绿色、脉间呈较对称黄化，新梢叶片常偏窄直立 |
| `5` | `S6_叶脉黄化疑似症状(非确诊HLB)` | 主脉及侧脉显著发黄肿大或木栓化（外观疑似症状） |
| `6` | `S7_均匀黄化疑似症状(非确诊HLB)` | 整叶均匀褪绿发黄（如根系受损、环割或氮素缺乏等通性外观黄化） |
| `7` | `S8_缺镁样症状` | 老叶叶尖与叶缘先黄化，基部沿中脉保留倒“V”形绿色区 |
| `8` | `S9_缺硼样症状` | 叶脉肿大木栓化开裂，或果皮坚硬增厚畸形 |
| `9` | `S10_炭疽病疑似症状` | 叶尖/叶缘褐色近圆形或云纹状坏死斑，边界较清晰 |
| `10` | `S11_脂点黄斑病疑似症状` | 叶背/叶面簇生黄褐色至黑褐色小粒点，周围伴黄色晕圈或脂斑 |
| `11` | `S14_溃疡病疑似症状` | 叶面/果面火山口状木栓化隆起病斑，叶片病斑周围常见黄晕 |
| `12` | `S13_煤烟病疑似症状` | 叶面/果面覆盖黑色煤粉状霉层 |
| `13` | `S12_藻斑苔藓附生症状` | 老叶表面附生灰绿色或黄褐色绒毛状/圆斑状藻类苔藓 |
| `99` | `U99_无法判断_转不确定隔离` | 反光、失焦、潜叶蛾虫道等不在 14 类体系内或专家肉眼无法确诊的样本 |
| `-1` | `DEL_非柑橘器官或无效伪框_删除` | 背景杂草、树干、地面、手指或严重重叠冗余框 |

> **针对胡柚实拍集中潜叶蛾卷叶/虫道的特别约定**：若叶片仅呈现潜叶蛾银白色蜿蜒虫道/卷叶而无上述 `0..13` 病害/缺素症状，统一标注为 `99`（并在 `annotator_note` 备注 `虫害_潜叶蛾非14类病害`），防止将虫害误计入病害正负样本。
