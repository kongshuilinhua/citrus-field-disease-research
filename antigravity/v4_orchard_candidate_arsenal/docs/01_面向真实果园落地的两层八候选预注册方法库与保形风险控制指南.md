## 一、设计动机：为什么用“两层八候选预注册库”替代“在源域死磕复杂逐框门控”？

1. **前置只读可行性审计（`phase0_readonly_oracle_and_predictability_audit.py`）已证伪“源域逐框学习门控”**：
   - 在唯一允许无偏选参的源域 `SciDB val`（`866` 图、`869` 框）上，零学习参数的单框静态对数校准 `Abl1` 已达 `90.44%`，与真值匹配的双向有效冲突框总共仅 **`[14, 18, 21]` 个**（其中 `YOLO 对、DINO 错` 的 `Case C` 平均仅 **`6.3` 个框**），逐框最优门控 $\alpha_i^* \in [0, 1]$ 的参数空间总上界仅 **`+0.76±0.30%`**。
   - 源域拟合的 14 维学习门控在 `val` 5 折交叉验证上倒退 `-0.51pt`，冻结迁移至 `testB / testC` 平均倒退 **`-1.41pt / -0.82pt`**；无正则 14 类独立权重因零冲突类退化至极端值 `0/1`，迁移至 `testB / testC` 倒退 **`-1.27pt / -1.10pt`**。
2. **真实胡柚/香柚果园场景（待采集/待专家盲评回填）存在客观未知性**：
   - 端侧手机推理 vs 云端服务器预标注尚未锁死；
   - 190 张田间实拍初筛显示 **83.2% 画面含 4 片以上背景叶、94.7% 主目标占比较大**；
   - 数据到位初期面临 **0 目标域标签**，随后逐步进入 **40~120 张专家复核标签 / 50~100 条 PCR 校准样本** 阶段。
3. **因此，最诚实、最稳健的工程与论文策略是**：
   - 在**不改动任何冻结基座权重（6 份权重 `SHA-256` 100% 锁定）、不接触任何测试集选参**的前提下，预先构建梯度清晰、机制互补的 **第一层（路线 1：5 个零样本检测校准候选 `C1–C5`）** 与 **第二层（路线 2：3 个选择性复核与保形风险控制候选 `R1–R3`）**，待真实果园真值到位后一次性盲测择优，彻底杜绝事后改模块作假。

## 三、第二层（路线 2）：选择性复核、有限样本保形风险控制与 PCR 分层送检候选（`R1–R3`）

全部实验严格遵守 **“校准集与评测集 100% 图像互斥（200 次独立随机互斥切分）”**，严禁在评测样本自身上估计风险或阈值。

### 3.1 候选 `R2`：有限样本保形风险控制（Conformal Risk Control, CRC — Angelopoulos et al., ICLR 2024）

当真实胡柚果园回填少量专家复核样本（如 $n_{\text{cal}} \in \{40, 80, 120\}$ 张图像）时，给定农技部门可容忍的最大自动放行错误风险上限 $\alpha_{\text{risk}} \in \{10\%, 15\%, 20\%\}$，利用单调有界主诊断损失 $L_i(\lambda) \in \{0, 1\}$ 计算有限样本保形阈值：

$$\hat{\lambda}_{\text{CRC}} = \inf\left\{\lambda : \frac{n_{\text{cal}}}{n_{\text{cal}} + 1}\hat{R}_{n_{\text{cal}}}(\lambda) + \frac{1}{n_{\text{cal}} + 1} \le \alpha_{\text{risk}}\right\}$$

- **实测结果（`n_cal = 80` 张互斥校准图，`200` 次切分 × 3 随机种子均值）**：

| 检测底座 | `testB` $\alpha=10\%$ 实测风险 / **自动放行率** | `testB` $\alpha=15\%$ 实测风险 / **自动放行率** | `testC` $\alpha=10\%$ 实测风险 / **自动放行率** | 无有限样本校正阈值（Naive）在 $\alpha=10\%$ 的超限风险 |
| :--- | :---: | :---: | :---: | :---: |
| `B0: Native YOLOv8n` | `10.16%` / `79.98%` | `14.33%` / `89.36%` | `9.95%` / `77.97%` | `11.29%`（明显超限违规！） |
| `B1: Full DINOv2` | `9.50%` / `87.47%` | `12.47%` / `97.50%` | `8.33%` / `94.66%` | `10.50%`（超限违规） |
| **`C1: Fast1Crop_StaticCalib`** | **`9.48%` / `93.48%`** | **`11.41%` / `99.06%`** | **`8.48%` / `96.15%`** | `10.26%` |

### 3.2 候选 `R1`（零标签视觉纠错送审）与候选 `R3`（软后验经验贝叶斯期望风险 PCR/混淆分层送审）

我们严格把**“视觉外观症状错判复核”**与**“潜伏病原学（PCR）疑似症状送检”**两类不同性质的任务拆开报告，避免混淆：

1. **零标签视觉外观错判捕获（`R1`，0 校准样本，`testB / testC`）**：
   - 当目标是捕获**模型视觉分类错误**时，零标签校准后验不确定度 `R1a: 1 - max_c p_C2(c|x)` 在 `5% / 10% / 20% / 30%` 人工复核预算下，在 `testB` 上即可捕获 **`35.3% / 60.1% / 88.7% / 96.6%`** 的视觉错判样本（为随机抽检的 **`7.1× / 6.0× / 4.4× / 3.2×`**），在 `testC` 上捕获 **`31.4% / 54.0% / 71.4% / 86.0%`**（高于显式加入跨模型 JS 散度的 `R1b` `35.1% / 51.2% / 75.9% / 90.7%`，诚实保留简单 `1 - max_p` 更优的消融结论）。
2. **小样本校准 PCR 疑似症状风险分层送检（`R3`，严格沿用仓库核定的 `597` 例对齐样本，200 次独立互斥划分 × 3 种子）**：
   - 当目标是弥合“视觉外观症状与 PCR 检测结果之间的潜伏偏差”时，单纯置信度在 `5%` 预算下仅捕获 `6.6%`（负向对照确认）。
   - 我们提出的 **`R3` 软后验经验贝叶斯期望风险**：
     $$S_{\text{PEB}}(x) = \sum_{c=1}^{14} p_{\text{cascade}}(c \mid x) \cdot \frac{n_c \hat{e}_c + m \bar{e}}{n_c + m} \quad (m = 5)$$
     利用级联校准后的全 14 类软概率分布对经验贝叶斯收缩类风险求期望，自动打破同预测类内部的离散平局（例如主判为溃疡病但次级概率含斑驳黄化的样本会被优先上浮送检），**在 `G1`（严格四黄化症状）与 `G2`（含缺锌样黄化五症状）双口径、全部校准规模（$n_{\text{cal}} = 50, 100, 200$）下全面超越 DS 硬类别先验**：

| 口径与校准集规模（互斥划分） | 送检策略 | `5%` 预算捕获率 | `10%` 预算捕获率 | `20%` 预算捕获率 | `30%` 预算捕获率 |

## 四、真实胡柚 / 香柚果园数据到位后的冻结执行规范（已收敛为唯一主方法 `C3`）

> **2026-11-27 Stage 2b v1.1 统计收尾声明更新**：
> 1. 主方法冻结配置与全部 12 份底层权重 `SHA-256` 保持锁定于 `configs/c3_frozen_manifest.json`（含零调参等权汇报口径 `C3_equal [0.30, 0.35, 0.35]`、冻结配置 `C3 [0.30, 0.20, 0.50]`、单刀框外高斯模糊遮罩 `G2_blur [0.30, 0.70]`、`A4b` 及 `C2` 按种子 `γ`）。
> 2. 命令行推理工具 `scripts/orchard_plug_and_play_cli.py` 提供 `--mode check_manifest`、`--mode preannotate` 与 `--mode eval_frozen6`（兼容 `eval_frozen5 / eval_frozen4` 别名，真实果园一次性盲测预注册冻结六模型 `YOLOv8n / Full DINOv2 / C1 / G2_blur / A4b / C3`，强制一对一匹配、不确定标注隔离与按采集簇 Bootstrap）。

1. **阶段 A：刚拿到未标注果园原图（0 专家真值，需快速预标注并挑选疑难图送专家复核）**
   - **云端批量预标注首选**：运行 **`C5a`** 或 **`C3`** 生成预标注框与 **`Top-3` 可确认症状候选卡片**（`Top-3` 覆盖率 `>99%`，非生物缺素胁迫自动标记 OOD 概率）；
   - **专家优先盲评抽样**：直接用 **`R1a`（校准后验 `1 - max_p`）** 抽取前 `10%–20%` 高不确定度图像优先请农技专家复核（严守同叶/同树/连拍采样隔离簇不跨划分拆分的规则）。
2. **阶段 B：获得首批 40~100 张独立果园专家复核真值（无 PCR，面向手机 App 上线）**
   - **若部署在端侧/低延迟环境（`<17 ms`）**：对比预冻结的 **`C1`** 与 **`C2`**（若新手机近景特写导致检测器马氏距离均值 `z_Maha > 0.4`，选用带 OOD 防护的 `C2`；否则选极简 `C1`）；
   - **若允许双次裁剪（`~18 ms`）且跨品种差异明显（甜橙→常山胡柚）**：优先选用零多尺度 MLP 参数的 **`C3: ZeroMLP_DualCrop_CoreStd`**；
   - **风险门禁**：在互斥校准簇上运行 **`R2 (CRC)`** 锁定保形阈值 $\hat{\lambda}_{\text{CRC}}$，保证自动展示结果受有限样本风险上界保护。
3. **阶段 C：获得 50~100 条同果园带实验室 PCR 结果的校准样本（面向防疫哨点筛查）**
   - 直接启用 **`R3: 软后验经验贝叶斯期望风险 S_PEB`** 按防疫预算（`5%–20%`）输出送检清单，并同时报告 `G1/G2` 口径，绝不将视觉黄化直接输出为“确诊黄龙病”。
