## 一、立项依据（基于 3 随机种子真实错误分解与 Oracle 上界诊断）

前期对 `YOLOv8n` 与 `DINOv2` 在 `SciDB` 3 个随机种子上的逐框诊断揭示了三条硬事实：
1. **定位框已高度饱和，无需框坐标回归**：在真实 `val / testB / testC` 原图上，`YOLOv8n` 的类无关召回率（`IoU≥0.5`）达 **`99.88% / 99.83% / 99.83%`**，匹配框平均 IoU 达 **`95.27% / 93.96% / 94.91%`**（`0.50≤IoU<0.75` 的比例仅 `0.12%–0.50%`，93% 以上候选框已达 `IoU≥0.90`）。因此不引入伪需求的框回归分支，严格聚焦跨视角类别冲突与置信度排序失准。
2. **单向硬覆盖造成严重的“反向改错（C 类）”与“双视角盲区（D 类）”**：
   - 在 `testB / testC` 上，全量 `DINOv2`（`1.25×` 裁框硬覆盖）虽然正向救回了 `91.0 / 119.7` 个 `YOLOv8n` 错框（B 类），但同时将 **`23.0 / 24.0` 个 `YOLOv8n` 原本靠整图上下文判对的框改错（C 类）**，另有 `36.0 / 33.7` 个框两者皆错（D 类）。
   - 固定 `YOLOv8n` 框不变，仅在 `YOLO vs DINOv2` 间做理想选择（`Oracle_Choice`），`testB / testC` 的 `COCO AP50-95` 上界即高达 **`80.02±0.79%`（较全量 DINOv2 `+4.12pt`）** 与 **`87.82±0.38%`（`+4.52pt`）**；若进一步利用多尺度相对上下文攻克部分 D 类框，固定框完美分类上界高达 **`84.76%` / `92.69%`**。
3. **源域错误样本极度稀疏（`<1.5%`），直接监督回归 $\Delta U$ 存在样本饥饿**：在 `SciDB val` 上 `A 类（两者皆对）` 高达 `96.95%`，`B / C / D` 合计仅 `3.05%`（训练集内部更低于 `0.5%`）。直接用干净源域样本监督训练风险/收益预测器会导致正样本饥饿与过拟合。

## 二、核心技术创新（非简单模块拼接）

### 创新 1：面向源域样本饥饿的反事实失效模式合成与收益学习（Counterfactual Gain-Aware Learning）
- 不依赖任何目标域数据，在源训练集 `SciDB train` 上针对跨场景真实失效机理构造**结构化反事实单视图退化对**：
  1. *模拟整图分辨率受限与背景干扰（诱发 B 类，$\Delta U > 0$）*：对整图检测侧特征/分布施加尺度下采样模糊与类间混淆温度扰动；
  2. *模拟局部裁框截断、偏心遮挡与白板/林间曝光偏移（诱发 C 类，$\Delta U < 0$）*：对局部紧裁框施加随机边界截断、局部遮挡或强光度/色温偏移，而保持整图与扩框参照完整；
- 以真实交叉熵损失下降量 $\Delta U = \mathcal{L}_{\text{CE}}(\mathbf{p}_{\text{det}}, y) - \mathcal{L}_{\text{CE}}(\mathbf{p}_{\text{ref}}, y)$ 为监督信号，联合检测器边界模糊度（熵/置信度间隔）与颈部流形偏移度，学习**第一级零裁图开销的收益感知预门控 $G_\theta$** 与**第二级动态可靠性仲裁权重**。

### 创新 2：目标—近邻环境相对差分表征与按需三级跨粒度升级（On-Demand Tri-Granularity Relational Escalation）
- 突破传统两阶段“一刀切固定 `1.25×` 裁框”的局限，建立**三级按需推理链路**：
  - **Level 0（整图直通）**：当 $G_\theta$ 判定预期纠错净收益低于源域标定阈值时，直接保留 `YOLOv8n` 原预测（零裁图开销）；
  - **Level 1（标准紧框快速核验，`1.25×`）**：触发后先提取标准 `1.25×` 器官框特征 $\mathbf{z}_{\text{std}}$。若整图 14 类分布 $\mathbf{p}_{\text{det}}$ 与标准框分布 $\mathbf{p}_{\text{std}}$ 高度一致且低熵，直接完成校准融合并退出；
  - **Level 2（跨视角冲突按需升级：内部叶肉核 `0.82×` + 近邻枝叶环境框 `2.50×` 相对差分）**：仅当整图与 `1.25×` 出现预测冲突或高不确定性（对应 C 类与 D 类高危池）时，追加提取**去边框背景的内部核心视图 $\mathbf{z}_{\text{core}}$（`0.82×`）**与**含同枝邻叶光照参照的环境视图 $\mathbf{z}_{\text{ctx}}$（`2.50×`）**，通过显式的**目标—环境特征差分 $\mathbf{z}_{\text{core}} - \mathbf{z}_{\text{ctx}}$ 与框几何条件门控 $\mathbf{g}(b)$** 剥离白板强反光与果园色温干扰，专门攻克 C 类改错与 D 类共错样本。

### 创新 3：定位置信度与多视角分类后验解耦校准及同器官假设归并（Objectness-Decoupled Score Calibration）
- 从 `YOLOv8n` 检测头 8,400 个锚点精确恢复每个候选框完整的 **14 类原始概率向量 $\mathbf{p}_{\text{det}} \in (0,1)^{14}$**（保留次高类语义证据），在温度校准对数几率空间执行实例自适应加权融合，并将最终检测排序分分解为 `YOLOv8n` 框级前景定位置信度 $s_{\text{obj}} = \max_c p_{\text{det}}(c)$ 与跨粒度仲裁分类后验 $p_{\text{arb}}(\hat{c})$ 的几何耦合 $s_{\text{final}} = s_{\text{obj}}^{\beta} \cdot p_{\text{arb}}(\hat{c})^{1-\beta}$，最后经同类别 NMS 消除跨类重判产生的同叶重复假阳性。
