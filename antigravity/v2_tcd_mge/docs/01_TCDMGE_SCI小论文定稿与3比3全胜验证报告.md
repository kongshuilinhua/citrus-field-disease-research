## 一、问题诊断与立论逻辑（从实测证据出发，不做伪需求）

通过对 `YOLOv8n` 与全量 `DINOv2` 二阶段基线在 3 个随机种子上的逐框错误分解（Oracle 诊断），我们确立了本方法立论的三条实证支柱：

1. **排除“框坐标回归”伪需求，锁定跨视角认知冲突真瓶颈**：在真实 `SciDB val / testB / testC` 原图上，`YOLOv8n` 类无关召回率达 `99.83%–99.88%`，匹配框平均 IoU 高达 `93.96%–95.27%`（`IoU < 0.75` 的比例不足 `0.5%`）。跨场景掉点并非源于框坐标偏移，而是源于**单向硬覆盖机制下的跨视角认知冲突**：在 `testB / testC` 上，全量 `DINOv2`（`1.25×` 单一裁框）虽救回了 `91.0 / 119.7` 个 `YOLOv8n` 错框（B 类），却同时将 **`23.0 / 24.0` 个 `YOLOv8n` 原本靠整株上下文判对的框改错（C 类）**，另有 `36.0 / 33.7` 个框因白板强反光、果园阴影色偏或局部截断导致两者皆错（D 类）。固定原框下的分类选择 Oracle 上界达 `80.02% / 87.82%`（较全量 `DINOv2` 存在 `+4.12pt / +4.52pt` 净空间，完美分类上界更达 `84.76% / 92.69%`）。
2. **揭示源域样本内记忆效应对“监督式路由权重学习”的系统性偏置**：`YOLOv8n` 在其训练过的源训练集 `SciDB train` 上准确率超 `99.5%`。对照实验（`CG-GAR v1/v2`）证实：任何在源训练集上直接监督学习跨视角融合权重的神经网络，都会高估检测器的样本内置信度（即便在同分布 `SciDB val` 上亦比等权池化低 `0.18pt`，并在白板偏移集 `testC` 退化 `-2.3pt`）。
3. **提出无偏解析仲裁与目标—近邻环境相对差分机制（`TCD-MGE`）**：针对上述三大瓶颈设计三个紧密耦合的原创机制。

## 二、`TCD-MGE` 方法三大核心创新

### 1. 锚点级 14 类全分布恢复与前景定位—语义分类解耦校准
传统两阶段级联仅读取 NMS 后的 Top-1 类别标量，丢弃了检测器在次优候选类上的多类证据。`TCD-MGE` 直接从检测头 8,400 个锚点精确恢复候选框完整的 14 类原始概率分布 $\mathbf{p}_{\text{det}} \in (0, 1)^{14}$，并将最终检测排序置信度解耦为**检测器框级前景定位质量 $s_{\text{obj}} = \max_c p_{\text{det}, c}$** 与**跨粒度仲裁语义后验 $p_{\text{arb}}(\hat{c})$** 的几何耦合：
$$s_{\text{final}}(b, \hat{c}) = s_{\text{obj}}^{\beta} \cdot \big(p_{\text{arb}}(\hat{c})\big)^{1-\beta}$$
随后执行类别一致空间归并（Class-wise NMS），消除跨类纠错引发的同器官重复假阳性。

### 2. 三信号驱动按需多粒度升级与目标—近邻环境相对差分表征（$R_\psi$）
为同时解决 C 类（紧框截断丢失上下文）与 D 类（白板强反光/林间色温偏移干扰单框），避免对简单框盲目提取多视图：
- **Level-1 快速双视角初检**：对前景候选框仅提取标准器官框 $v_{\text{std}}$（`1.25×`），计算跨粒度预测不一致指示 $\mathbb{I}[\hat{y}_{\text{det}} \neq \hat{y}_{\text{std}}]$、局部预测归一化香农熵 $H_{\text{norm}}(\mathbf{p}_{\text{std}})$ 以及检测器颈部多尺度特征马氏偏移 $\tilde{d}_M(\mathbf{z}_{\text{neck}}, \hat{y}_{\text{det}})$。
- **Level-2 三信号按需升级**：仅当触发联合风险判据
  $$\mathcal{E}(x) = \mathbb{I}\big[\hat{y}_{\text{det}} \neq \hat{y}_{\text{std}}\big] \;\lor\; \mathbb{I}\big[H_{\text{norm}}(\mathbf{p}_{\text{std}}) > \tau_H\big] \;\lor\; \mathbb{I}\big[\tilde{d}_M(x) > \tau_M\big]$$
  （其中 $\tau_H, \tau_M$ 严格按源域 `val` `82%` 分位标定冻结，源域超 `71%` 样本直接快速退出），才追加提取**剥离边框底板的内部叶肉核视图 $v_{\text{core}}$（`0.82×`）**与**含同枝邻叶光照参照的近邻环境视图 $v_{\text{ctx}}$（`2.50×`）**，输入仅在源训练集冻结特征上训练的**目标—环境相对差分关系头 $R_\psi$**：
  $$\boldsymbol{\ell}_{\text{rel}} = R_\psi\Big(\big[\mathbf{z}_{\text{std}},\, \mathbf{z}_{\text{core}},\, \text{Norm}(\mathbf{z}_{\text{core}} - \mathbf{z}_{\text{ctx}}),\, \text{Norm}(\mathbf{z}_{\text{std}} - \mathbf{z}_{\text{ctx}}),\, \phi_{\text{geom}}(\mathbf{g}(b))\big]\Big)$$
  利用显式特征差分 $\mathbf{z}_{\text{core}} - \mathbf{z}_{\text{ctx}}$ 抵消共模环境光色偏与背景底板干扰。

### 3. 零过拟合流形衰减香农确信度对数意见池（Manifold-Attenuated Logarithmic Opinion Pooling）
摒弃易受源训练集记忆效应误导的黑盒权重网络，采用具有严格信息论与几何解释的实例级自适应对数池化：各局部视图权重正比于其香农确信度 $c_k(x) = 1 - H_{\text{norm}}(\mathbf{p}_k(x))$，而整图检测分布的权威度随其颈部特征偏离源域流形的程度呈指数衰减：
$$u_{\text{det}}(x) = w_0 \big(1 - H_{\text{norm}}(\mathbf{p}_{\text{det}})\big)\exp\!\big(-\gamma \max(0, \tilde{d}_M(x))\big), \quad u_k(x) = w_k \big(1 - H_{\text{norm}}(\mathbf{p}_k)\big)$$
$$\log \mathbf{p}_{\text{arb}}(x) = \sum_{k \in \mathcal{V}(x)} \frac{u_k(x)}{\sum_{j \in \mathcal{V}(x)} u_j(x)} \log \mathbf{p}_k(x) - \log Z(x)$$
当源域无偏移（$\tilde{d}_M \le 0$）且局部裁框因遮挡高熵时，高确信度的整图分布自动主导以保护 C 类样本；当发生跨背景高置信幻觉（$H_{\text{det}} \approx 0$ 但 $\tilde{d}_M \gg 0$）时，$\exp(-\gamma \tilde{d}_M)$ 自动压制整图幻觉，交由内部叶肉与环境差分表征主导纠错。
