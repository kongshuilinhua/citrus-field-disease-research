# Stage 2b 专题报告（v1.1 勘误定稿版）：G1–G4 同几何背景干预、“两刀 vs 单刀遮罩”判决检验与预注册 6 模型盲测规范

## 一、v1.1 勘误声明与核心判决结论

1. **“两刀是否必要”判决检验结论（`G3 − G2` 与 `G3 − G2_blur`, `B = 1,000` 配对 Bootstrap）**：
   - 在复杂田间背景 `SciDB testB` 上：
     - `G3 (冻结 C3 [0.30,0.20,0.50]) − G2_blur (单刀模糊遮罩 [0.30,0.70])` = **`+0.122%`**（95% CI `[-0.603%, +0.906%]`, **`p = 0.7800`**），逐种子 **`[-0.203%, +0.740%, -0.171%]`**（逐种子 `p = [0.760, 0.314, 0.772]`）；
     - `G3_eq (零调参等权 [0.30,0.35,0.35]) − G2_blur` = **`-0.237%`**（95% CI `[-1.002%, +0.531%]`, **`p = 0.5540`**），逐种子 **`[-0.026%, -0.027%, -0.659%]`**（逐种子 `p = [0.950, 0.964, 0.332]`）；
     - `G3 − G2 (单刀灰环)` = `+0.502%`（`p = 0.1920`，逐种子 `[+0.851%, +0.715%, -0.059%]`）；`G3_eq − G2` = `+0.143%`（`p = 0.7180`）。
   - 在白板背景 `SciDB testC` 上：`G3 − G2_blur = +0.528%`（95% CI `[-0.152%, +1.248%]`, `p = 0.1340`，逐种子 `[+1.243%, -0.937%, +1.278%]`）；`G3_eq − G2_blur = +0.144%`（`p = 0.7300`）。
   - **判定结论**：第二次裁剪（`0.82×`）相对“单刀 `1.25×` + 框外高斯模糊遮罩”的附加收益**不显著**（未达到 `≥ +0.40pt 且 p < 0.05`）。因此按预注册判定规则，**不修改冻结协议**，将论文方法与讨论定位为：“`G2_blur` 单刀框外遮罩为抑制田间邻叶干扰的最简实现（`1.0×` ViT FLOPs），`C3` 双尺度为无需显式框边界遮罩的等效增强实现（`2.0×` ViT FLOPs）”。
2. **两项重要勘误**：
   - **逐种子异质性披露**：`testB` 上冻结 `C3` 的 $\text{DiD}_{\text{gray}}$ 逐种子为 **`[+0.505%, -1.989%, -1.455%]`**（Seed 0 无收缩），$\text{DiD}_{\text{blur}}$ 逐种子为 **`[-0.154%, -1.011%, -1.503%]`**；所谓增益收缩系 **`2/3` 种子（Seed 1、Seed 2）现象**。
   - **撤回等权口径显著性误报**：零调参等权 `C3_equal` 在 `testB` 上的 $\text{DiD}_{\text{gray, eq}} = -0.621\%$（**`p = 0.1220`**）、$\text{DiD}_{\text{blur, eq}} = -0.688\%$（**`p = 0.0980`**），均**不显著**；此前写作“同样显著收缩”系事实性表述错误，已全部修正。
