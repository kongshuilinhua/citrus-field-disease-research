## 一、实验目的与受控设计（修正原 H1/H2 单一灰环掉点误判逻辑）

若仅观察“将 `1.25×` 外环置灰后与 `0.82×` 融合是否掉点”，一旦精度下降，无法区分是“背景隔离本身有效”还是“固定 `128` 灰色矩形阶跃边界引入新的分布偏移与伪影、或损失叶缘局部上下文”。为此，我们在**相同图像、相同候选框、相同冻结权重与相同后处理**下，构建 `G1–G4` 受控四组实验并增设 **`31×31` 高斯模糊外环（`G2_blur / G4_blur`）** 对照：

1. **严格同几何与框内像素恒等验证**：
   - `1.25×` 裁剪的中心、边长、缩放插值及 **`1.00×` 检测框内部像素 `[py1:py2, px1:px2]` 在 `real / gray128 / blur31` 三种模式下 100% 逐字节恒等**（实测 `real` 与缓存特征最大绝对误差 `≤ 3.5e-5`）。
   - 几何统计显示，由于柑橘叶片与枝梢普遍呈狭长非正方形长宽比，方形 `1.25×` 的 `224×224` 视图中位于 `1.00×` 检测框外部的外环像素平均占总面积的 **`43.76%`（`testB`，中位数 `45.25%`）**、`45.92%`（`val`）和 `49.70%`（`testC`）。
2. **核心双尺度增益与双重差分（Difference-in-Differences, DiD）定义**：
   $$\Delta_{\text{real}} = \text{AP}(G3) - \text{AP}(G1), \quad \Delta_{\text{gray}} = \text{AP}(G4) - \text{AP}(G2), \quad \Delta_{\text{blur}} = \text{AP}(G4_{\text{blur}}) - \text{AP}(G2_{\text{blur}})$$
   $$\text{DiD}_{\text{gray}} = \Delta_{\text{gray}} - \Delta_{\text{real}}, \quad \text{DiD}_{\text{blur}} = \Delta_{\text{blur}} - \Delta_{\text{real}}$$

### 2.2 机制判据逐条核对
1. **为什么增设模糊外环（`G2_blur`）非常关键？**  
   在复杂田间多叶 `testB` 上，固定 `128` 灰环使单尺度提升 `+0.626%`（$p=0.156$），并使双尺度 `G4` 相对 `G3` 微降 `-0.354%`（说明固定灰边确实存在轻微矩形阶跃边界伪影！）；而改用保持局部亮度连续、仅抹除邻叶高频病斑/叶脉纹理的高斯模糊外环后，单尺度 `G2_blur` 相对 `G1` **显著提升 `+1.006%`（95% CI `[+0.129%, +1.870%]`, $p = 0.024$）**，且 `G4_blur` 完全不低于 `G3`（`79.30%` vs `79.19%`, `+0.116%`, $p=0.758$）。
2. **双尺度增益的同步显著收缩（直接支持背景干扰抑制机制）**：  
   在 `testB` 上，当 `1.25×` 的框外杂叶干扰被灰环或模糊外环中和后，额外引入 `0.82×` 紧致视角的边际增益由原始背景的 **`+1.128%`（$p<0.001$）骤降至 `+0.148%`（灰环）和 `+0.238%`（模糊）**；双重差分 $\text{DiD}_{\text{gray}} = -0.980\%$ ($p<0.001$) 与 $\text{DiD}_{\text{blur}} = -0.889\%$ ($p=0.014$) 均统计显著（在零调参等权 `[0.30, 0.35, 0.35]` 下同样显著收缩 `~80%`）。
3. **跨场景依赖性诚实披露**：  
   在无邻叶背景干扰的均匀白板 `testC` 与干净源域 `val` 上，框外干预不产生单尺度正向跃升（`testC` `+0.12%~+0.26%`, $p>0.55$；`val` `-0.17%~-0.23%`），说明背景干扰抑制效应明确集中于**田间多叶交叠冠层场景**。

## 三、真实果园外部验证协议定型（5 冻结模型 + 一对一匹配 + 按簇 Bootstrap）

1. **揭盲前预声明 5 模型分工**：
   - `B0_Native_YOLOv8n`：原始单阶段检测基线；
   - `B1_Full_DINOv2_125_Hard`：两阶段硬覆盖强基线；
   - `C1_SingleScale_125_Calib`：单尺度校准后验融合主对照；
   - `A4b_FlipTTA_125_HFlip_Calib`：常规双视角翻转 TTA 预先指定补充对照；
   - **`C3_DualScale_082_125_Calib`：唯一冻结主方法**（主研究问题对比 `C1` 与 `Full DINOv2`，`A4b` 为补充对照）。
2. **评测器三项方法学加固（已在 `run_stage2b_gray_ring_mechanism_and_a4b_speed.py` 模块 0 通过自动化核验）**：
   - **一对一（1-to-1）置信度优先匹配**：按预测分数降序匹配真值框，杜绝一个预测框同时命中两片相邻重叠真值叶；
   - **完备五分法真值框归因**：`定位且分类正确 + 定位准但分类错 + 无候选框(IoU<0.1) + 定位偏差(0.1≤IoU<0.5) + 分数/NMS/重叠竞争丢失 ≡ 可确认真值框总数`；同时自动隔离专家标注的 `uncertain` 疑难框；
   - **按采集簇（Cluster-level）同步配对 Bootstrap (`B = 1,000`)**：按同树/同枝连拍 `cluster_id` 整簇有放回抽样，输出 `AP50-95 / AP50 / Recall@0.5 / Matched_Top1 / MissPenalized_Top3` 的簇校正 95% 置信区间与 $p$ 值。
