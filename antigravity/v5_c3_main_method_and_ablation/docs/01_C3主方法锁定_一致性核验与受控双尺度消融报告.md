## 二、第二阶段（Stage 2）：受控双尺度消融（`A1–A5`）与单自由度权重稳健性分析

### 2.1 实验控制与权重自由度说明
- **零新模型训练、零额外 MLP 参数**：`A1–A5` 100% 共享同一组冻结 `YOLOv8n` 与冻结 `DINOv2 (ViT-S/14 LP-FT)` 线性分类头（额外可训头参数恒为 **`0`**）及相同后处理。
- **消除 $w_{\text{det}}$ 混杂与明确单独立自由度**：在总权重和固定为 $1$、检测器先验权重固定为 $w_{\text{det}} = 0.30$ 后，双视角视觉权重 $(w_{\text{core}}, w_{\text{std}})$ 满足 $w_{\text{core}} + w_{\text{std}} = 0.70$，**实际上仅含 1 个独立自由度（而非 2 个）**。
- **主方法保留冻结 `C3`，等权 `C3_equal` 置于消融表**：主表保留已冻结实现的 $C3 = [0.30, 0.20, 0.50]$（源自 `v4` 在源域 `SciDB val` 上锁定的先验配置），消融表同时报告零调参视觉等权版本 $C3_{\text{equal}} = [0.30, 0.35, 0.35]$ 与逐种子 `val` 网格版本，证明正向收益不依赖精细调权。

  1. **复杂田间多叶场景（`testB`）直接符合判据第 1 条**：仅将单尺度 `1.25×` 框外高频杂叶模糊化（`G2_blur`）即显著提升单尺度精度 **`+1.01pt`（$p=0.024$；纯 `DINOv2` 提升 `+1.69pt`）**，灰环亦提升 `+0.63pt`（因人工矩形灰边存在轻微阶跃伪影，涨幅小于自然过渡的高斯模糊）；与此同时，引入 `0.82×` 的双尺度增益由原始背景的 **`+1.13pt`（$p<0.001$）同步大幅收缩至 `+0.15pt`（灰环，$\text{DiD} = -0.98\text{pt}, p<0.001$）与 `+0.24pt`（模糊，$\text{DiD} = -0.89\text{pt}, p=0.014$），缩减幅度达 `79%–87%`**。这有力支持“抑制 `1.25×` 框外邻叶与枝条背景干扰是 `C3` 在复杂田间场景收益的主要来源”，且 `C3` 无需依赖精确框边缘掩膜即可通过 `0.82×` 中心视角在推理时自然实现该抗干扰效果。
  2. **跨场景响应符合判据第 4 条（场景依赖性）**：在本来已无邻叶遮挡的均匀白板 `testC` 与源域 `val` 上，框外干预对单尺度并无显著增益（`testC` `+0.12~+0.26pt`，$p>0.55$；`val` `-0.17~-0.23pt`），`testC` 上的适度收益主要体现一般双视角正则化（故与 `A4b` 翻转 TTA 表现接近）。

## 五、可直接用于论文初稿的《方法（Method）》数学公式规范

1. **候选区域生成与检测器锚点分布提取**：输入图像 $I \in \mathbb{R}^{H \times W \times 3}$ 经 `640×640` 等比例方形填充后输入 `YOLOv8n`，初始 NMS（$\tau_{\text{init}}=0.001, \text{IoU}=0.70$）输出 $\{b_i, s_i^{\text{det}}\}_{i=1}^{N}$（$s_i^{\text{det}} = \max_c \sigma(z_{i,c}^{\text{det}})$ 为最高类别 Sigmoid 分数，无独立 Objectness 分支）及 14 类原始对数几率 $z_i^{\text{det}}$。
2. **互补双尺度目标表征提取（`0.82×` + `1.25×`）**：对 $s_i^{\text{det}} \ge 0.08$ 的前景框按最大边长 $L_i = \max(w_i, h_i)$ 截取紧致中心视角（$r_{\text{core}} = 0.82$，抑制框外及四角邻叶杂乱背景）与标准目标视角（$r_{\text{std}} = 1.25$，保留叶缘与果蒂拓扑），单批次通过冻结 `DINOv2 (ViT-S/14)` 线性分类头得 $z_i^{\text{core}}, z_i^{\text{std}} \in \mathbb{R}^{C}$。
3. **温度缩放对数线性后验融合**：在源域验证集标定的温度 $(T_{\text{det}}, T_{\text{dino}})=(1.35, 1.15)$ 与固定权重 $(w_{\text{det}}, w_{\text{core}}, w_{\text{std}}) = (0.30, 0.20, 0.50)$ 下计算：
   $$\log \tilde{P}(y = c \mid I, b_i) = w_{\text{det}} \log \operatorname{softmax}\!\left(\frac{z_i^{\text{det}}}{T_{\text{det}}}\right)_c + w_{\text{core}} \log \operatorname{softmax}\!\left(\frac{z_i^{\text{core}}}{T_{\text{dino}}}\right)_c + w_{\text{std}} \log \operatorname{softmax}\!\left(\frac{z_i^{\text{std}}}{T_{\text{dino}}}\right)_c$$
   $$P_{\text{fuse}}(y = c \mid I, b_i) = \frac{\exp(\log \tilde{P}(y = c \mid I, b_i))}{\sum_{c'=1}^{C} \exp(\log \tilde{P}(y = c' \mid I, b_i))}, \quad \hat{c}_i = \arg\max_{c} P_{\text{fuse}}(y = c \mid I, b_i)$$
4. **统一几何置信度重算与类别内 NMS**：按 $\hat{s}_i = (s_i^{\text{det}})^{\beta} \cdot (P_{\text{fuse}}(y = \hat{c}_i \mid I, b_i))^{1 - \beta}$ ($\beta = 0.55$) 更新分数并执行类别内 `batched_nms (IoU = 0.70)`。
