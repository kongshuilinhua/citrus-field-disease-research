### 2.1 实验控制设计（彻底排除检测器权重混杂与普通双视角 TTA 解释）

- **零新模型训练、零额外 MLP 参数**：`A1–A5` 100% 共享同一组冻结 `YOLOv8n` 检测器与冻结 `DINOv2 (ViT-S/14 LP-FT)` 线性分类头（额外可训参数量恒为 **`0`**），后处理统一采用温度缩放对数后验融合 + 统一几何分数重加权 + 类别内 `batched_nms (IoU = 0.70)`。

## 三、可直接用于论文初稿的《方法（Method）》数学公式与推理流程规范

1. **候选区域生成与检测器锚点分布提取**：
   给定输入田间图像 $I \in \mathbb{R}^{H \times W \times 3}$，经 `640×640` 等比例方形填充后输入单阶段检测器 `YOLOv8n`，经初始非极大值抑制（阈值 $\tau_{\text{init}}=0.001, \text{IoU}=0.70$）得到候选框集合 $\{b_i, s_i^{\text{det}}\}_{i=1}^{N}$，其中 $s_i^{\text{det}} = \max_c \sigma(z_{i,c}^{\text{det}})$ 为对应特征图锚点的最高类别 Sigmoid 响应（注：`YOLOv8` 无独立 Objectness 分支）。保留对应的 $C=14$ 类原始检测对数几率 $z_i^{\text{det}} = \operatorname{logit}(\tilde{p}_i^{\text{det}}) \in \mathbb{R}^{C}$。
2. **互补双尺度目标表征提取（`0.82×` 紧致视角 + `1.25×` 标准视角）**：
   对满足 $s_i^{\text{det}} \ge \tau_{\text{fg}} (=0.08)$ 的前景候选框 $b_i = (x_i, y_i, w_i, h_i)$，以其几何中心为锚点、按最大边长 $L_i = \max(w_i, h_i)$ 截取两个互补方形尺度并缩放至 $224\times224$：
   - **紧致中心视角（$r_{\text{core}} = 0.82$）**：物理裁除检测框四角及外缘的非目标叶片、枝条与反光背景，聚焦病斑局部纹理；
   - **标准目标视角（$r_{\text{std}} = 1.25$）**：完整保留患病器官边缘轮廓、叶脉走向与果蒂拓扑结构。
   两个视图合并为单批次输入冻结微调的 `DINOv2 (ViT-S/14)` 编码器与线性分类头，输出两路类别对数几率 $z_i^{\text{core}}, z_i^{\text{std}} \in \mathbb{R}^{C}$（零额外多尺度 MLP 参数）。
3. **温度缩放对数线性后验融合（Calibrated Logarithmic Opinion Pooling）**：
   利用源域验证集标定的温度参数 $(T_{\text{det}}, T_{\text{dino}})$ 与单纯形融合权重 $(w_{\text{det}}, w_{\text{core}}, w_{\text{std}}) = (0.30, 0.20, 0.50)$（满足 $w_{\text{det}} + w_{\text{core}} + w_{\text{std}} = 1$），计算校准融合后验分布：
   $$\log \tilde{P}(y = c \mid I, b_i) = w_{\text{det}} \log \operatorname{softmax}\!\left(\frac{z_i^{\text{det}}}{T_{\text{det}}}\right)_c + w_{\text{core}} \log \operatorname{softmax}\!\left(\frac{z_i^{\text{core}}}{T_{\text{dino}}}\right)_c + w_{\text{std}} \log \operatorname{softmax}\!\left(\frac{z_i^{\text{std}}}{T_{\text{dino}}}\right)_c$$
   $$P_{\text{fuse}}(y = c \mid I, b_i) = \frac{\exp(\log \tilde{P}(y = c \mid I, b_i))}{\sum_{c'=1}^{C} \exp(\log \tilde{P}(y = c' \mid I, b_i))}, \quad \hat{c}_i = \arg\max_{c} P_{\text{fuse}}(y = c \mid I, b_i)$$
4. **统一几何置信度重算与重判后类别内 NMS**：
   为消除重判前后检测框置信度标度不一致导致的排序失真，对所有前景框统一按几何加权规则更新最终检测分数：
   $$\hat{s}_i = \left(s_i^{\text{det}}\right)^{\beta} \cdot \left(P_{\text{fuse}}(y = \hat{c}_i \mid I, b_i)\right)^{1 - \beta} \quad (\beta = 0.55)$$
   最后在全图候选框上按更新后的类别 $\hat{c}_i$ 与分数 $\hat{s}_i$ 执行类别内非极大值抑制（`IoU = 0.70`），消除同一叶片上因重分类汇聚到同一正确类别而产生的重复框。
