# SCI 小论文终稿方法定稿报告：输入级隔离多粒度差分（IGD-DCR）与输出层空间 Token 正交剥离（BG-OPTA）受控机理研究

- **定稿日期**：2026-11-26
- **归档目录**：`antigravity/v3_bgopta_and_dtemop/`（与仓库内 GPT 及 DeepSeek 目录严格物理隔离）
- **方法简称与全称**：
  - 主推精简终稿架构：**IGD-DCR**（*Input-Isolated Multi-Granularity Differential Representation & Objectness-Decoupled Calibration Refinement*，面向跨背景柑橘病害检测的输入级隔离多粒度目标—环境差分与定位置信度解耦精化方法），提供 **GPU 单批并行实时模式（`IGD-DCR-Batch`，`53.7 FPS`）** 与 **边缘算力节省模式（`IGD-DCR-Esc`，无参数分歧触发，省 `66%–96%` 额外 ViT 计算）** 两套无冗余部署形态；
  - 关键受控反证探针：**BG-OPTA**（*Single-Pass Box-Guided Background Subspace Orthogonal Projection & Token Aggregation*，物理隔离全部测试集、纯源域预注册锁定的单趟 `1.50×` 输出层空间 Token 背景正交剥离方法）。

## 一、核心科学问题与四大立论支柱（逐条回应审稿级质疑）

针对前期 `TCD-MGE (v2)` 复核中暴露的四个核心审稿问题——**(1) 为什么不能靠普通特征拼接或单次扩框输出层剥离替代多尺度输入裁剪？(2) 复杂三信号自适应门控为何精度略低于固定三视角且延迟慢 66%？(3) `SciDB testB/testC` 与 `Zenodo` 的方法论定位及 `9–13` 类映射漏洞修复；(4) 真正零接触独立数据的单次冻结盲测**——本终稿通过严格零泄漏受控实验给出了完整闭环证明：

### 支柱 1：证明“框回归”是伪需求，锚点 14 类分布恢复 + 定位置信度解耦校准是零额外裁剪开销的基础增益
在真实 `SciDB val / testB / testC` 上，原生 `YOLOv8n` 类无关召回率已达 **`99.88% / 99.83% / 99.83%`**，匹配框平均 IoU 高达 **`95.27% / 93.96% / 94.91%`**（`0.50 ≤ IoU < 0.75` 的框不足 `0.5%`）。跨背景崩塌的真因是分类后验偏移与置信度排序失准。从 8,400 个锚点恢复完整 14 类对数分布 $\mathbf{p}_{\text{det}}$，并将检测分分解为前景定位分与精化分类后验的几何耦合：
$$s_{\text{final}}(b, \hat{c}) = s_{\text{obj}}^{\beta}\cdot p_{\text{ref}}(\hat{c})^{1-\beta}$$
仅用单紧框（`1.25×`）即在零额外 ViT 裁剪开销下将 `SciDB val / testB / testC` 从 `Full DINOv2` 硬覆盖的 `89.46% / 75.90% / 83.30%` 推升至 **`90.51% / 78.37% (+2.47pt) / 83.42%`**。

### 支柱 2：通过零泄漏预注册探针 `BG-OPTA`，首次定量揭示 ViT 内部“自注意力前向跨补丁污染”效应，证明输入级空间隔离的不可替代性
审稿人最自然的疑问是：*既然 `DINOv2` 输出 `16×16=256` 个空间 Patch Token，为何不只截取一次 `1.50×` 扩框，直接利用已知框边界从外周环带提取背景正交基 $\mathbf{U}_{\text{bg}} \in \mathbb{R}^{3\times 384}$，在输出层剥离背景分量（`BG-OPTA`）？*

我们在**物理隔离全部测试集**的前提下（`phase1_source_only_train_and_select.py`），仅用 `SciDB train / val` 训练并一次性锁定 `BG-OPTA` 四级消融权重（登记 SHA-256 后单次测试），揭示了两条兼具正反两面价值的物理规律：
1. **输出层正交投影确实优于普通特征拼接，且无需掩膜即可抑制框内四角背景**：
   - 在 `CitrusUAT`（`N=443`）真实物理叶片掩膜审计中（模型全程零掩膜输入），`BG-OPTA` 自动压制了矩形框内 **`67.71%`**（3 种子 `[69.71%, 65.37%, 68.04%]`）的非叶片灰底四角权重，使真实叶肉特征纯度从 `95.84%` 提升至 **`97.39%`**；
   - 在相同 `1.50×` 单框输入下，`BG-OPTA (S3)` 在源内合成背景偏移集 `source_dev_bgshift`（`90.11%` vs 普通拼接 `S1` `87.44%`、`[CLS]` `S0` `83.72%`）、`SciDB testB`（`75.94%` vs `S1` `75.21%`，3/3 胜）及修复版零丢框 `Zenodo`（2类 `43.38%` vs `Full DINOv2` `41.81%`、`S1` `42.98%`，3/3 种子全胜）上一致胜出。
2. **但输出层事后剥离无法逆转 ViT 12 层全局自注意力内部的“前向特征串扰”**：
   - 将单次输入从 `1.25×` 扩至 `1.50×` 不仅使前景叶片像素面积缩水 `30.6%`，更使占画布 `56%` 的外周强反光白板（`testC`）或林间杂枝（`testB`）补丁在 `DINOv2` **全部 12 层全局自注意力（Global Self-Attention）的 Key/Value 交互中提前污染了叶片内部 Token**，导致 `1.50× [CLS] (S0)` 在 `testB / testC` 上从 `78.37% / 83.42%` 暴跌至 `74.24% / 78.30%`（`-4.13pt / -5.12pt`）！即便输出层正交剥离追回 `+1.70pt / +1.01pt`（达 `75.94% / 79.31%`），仍远低于输入级隔离方法 `IGD-DCR`（**`79.28% / 85.09%`**，相差 **`+3.34pt / +5.78pt`**）！
   - **核心机理定论**：对抗剧烈背景反光与色偏，**必须在特征进入 ViT 全局自注意力之前，通过输入级空间裁剪隔离**——用 `0.82×` 内部叶肉核物理阻断边框背景进入自注意力窗口，再用独立编码的 `2.50×` 近邻环境向量在特征空间执行显式相对差分 $\text{Norm}(\mathbf{z}_{\text{core}}-\mathbf{z}_{\text{ctx}})$（较无训练纯三框 TTA `84.16%` 提升 `+0.93pt`，消除大框背景对 Seed 2 的拖累 `82.55% → 84.34%`）。

### 支柱 3：精简冗余门控，揭示 GPU 带宽受限下的“单批并行三视角（53.7 FPS）”与边缘端“无参数分歧按需升级”双形态优势
针对 `TCD-MGE (v2)` 比静态三视角 `Abl-3` 慢且精度略低 `0.18pt–0.25pt` 的问题，我们在消除重复 `letterbox` CPU 缩放后完成了 **RTX 4060 Ti 严格 FP32 七档零冗余测速**，彻底查明了硬件根因并给出诚实、清晰的架构收敛：
- **为什么两阶段串行升级在现代 GPU 上反而比全量单批三视角更慢？** 单图前景框数通常仅 `1.1–1.4` 个，`vit_small_patch14` 在极小 Batch 下属于典型的**显存带宽受限（Memory-Bandwidth Bound，读取 22M 模型权重耗时远大于矩阵乘计算）**。将 `[0.82×, 1.25×, 2.50×]` 合并为**单次 GPU Tensor 批前向（`IGD-DCR-Batch`）**只需读取一次 ViT 权重，实测 `testC` 端到端单图延迟仅 **`18.61 ms`（`53.7 FPS`，`val` 为 `19.89 ms / 50.3 FPS`）**——仅比单框 `Full DINOv2`（`14.09 ms`）多 `4.52 ms`，却比读取两次权重的串行升级 `TCD-MGE v2`（`24.13 ms`）快 **`22.9%`**，同时在**全部数据集上取得最高检测精度**！
- **那按需升级门控在什么场景真正有价值？** 删去冗余的熵与马氏阈值超参，仅保留**零阈值参数的跨视角预测分歧判据 $\mathbb{I}[\hat{y}_{\text{det}} \neq \hat{y}_{\text{std}}]$（`IGD-DCR-Esc`）**：在源域 `SciDB val` 上**仅需升级 `3.7%` 候选框（96.3% 样本单框退出，精度 `90.52%` 全场最高！）**，在 `testB / testC / Zenodo / SweetOrange` 上仅需升级 **`22.9% / 26.1% / 33.2% / 33.5%`** 候选框，为算力受限的田间边缘 CPU / 串行 NPU 节省 **`66%–96%` 的额外 ViT FLOPs**，且全基准 3/3 种子稳定击败 `Full DINOv2`！

### 支柱 4：规范划分基准角色、修复 `Zenodo` 14 类无遗漏映射，并完成 `Sweet Orange V1`（`N=1,389`）唯一一次零接触封口盲测
1. **诚实校准基准定位**：鉴于早期迭代观察过 `SciDB testC` 与 `Zenodo`，正式将 `SciDB testB / testC` 定位为**同源跨条件诊断基准**，将 `Zenodo 11148332` 定位为**外部果园探索验证集**；
2. **彻底修复 `Zenodo` 3 类漏映射缺陷**：针对 `zenodo11148332_coco` 原始标签定义（`health` / `HLB` / `ill`），将 SciDB 全 14 类完备映射为 `{0,1}→0, {2,3}→1, {4..13}→2`，实现 **100% 预测框保留（零静默丢框）**，并同步汇报把 `9..13` 严格计为错判（`-1`）的 GT 匹配准确率；
3. **新增真正零接触最终封口盲测（Vault Holdout）**：在从未参与任何检测模型设计的公开去重原图集 **`Sweet Orange V1`（`f7cr74mwpj` 去重保留集，`Healthy leaf` 547 + `Citrus canker` 588 + `Citrus greening` 254 = `1,389` 张）** 上，以完全冻结权重执行唯一一次端到端整图检测→器官诊断测试（严格遵循症状级表述，“黄化/斑驳疑似不等于 PCR 确诊黄龙病”）。
