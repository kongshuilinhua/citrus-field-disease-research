## 预注册实验清单与严格边界（开跑前冻结）

1. **实验 E1（`exp1_symtex_ablation_and_kd.py`）—— 细粒度病征表征组件消融、零增耗剪枝验证与蒸馏协同（3 随机种子 `0, 1, 2`）**
   - **目标**：
     - 严格拆解 `BASD`（双侧非对称空间差分）与 `II-HFR`（局部亮度归一化多尺度高频残差）对跨背景分类与叶片前景掩膜聚焦度（`Energy-Inside-Mask`）的独立贡献；
     - 验证**训练期辅助塑形 + 推理期剪除全部辅助分支（`3.35M` 零额外参数）**相对完整多分支推理是否零性能损失；
     - 验证在知识蒸馏（对齐预训练微调 DINOv2 教师特征与软分布）之上叠加 `SymTex`（`SymTex-KD-Pruned`）相对纯蒸馏（`Vanilla-KD`）的净增益，以及高精度档 `DINOv2-SymTex` 头的表现。
   - **对照矩阵（全部 3 种子 `0, 1, 2`，仅用 `SciDB val` 宏 F1 选最佳轮次，严禁使用 `testB/C` 或外部集选模）**：
     - 复用已归档参照：`B1_SingleStream`、`B3_MultiScale`、`B4_LocalGlobalConcat`（见上级目录 `Probe-C0`）；
     - 本轮新增训练并保存权重：`Abl_BASD_Pruned`（仅双侧非对称塑形，推理剪枝 3.35M）、`Abl_IIHFR_Pruned`（仅高频残差塑形，推理剪枝 3.35M）、`SymTex_Pruned`（BASD + II-HFR 联合塑形，推理剪枝 3.35M）、`Vanilla_KD`（纯教师蒸馏学生 3.35M）、`SymTex_KD_Pruned`（BASD + II-HFR + 教师蒸馏，推理剪枝 3.35M）、`DINOv2_SymTex`（高精度档 DINOv2 patch 非对称拓扑增强头）。

2. **实验 E2（`exp2_end2end_mgs_cascade_and_timing.py`）—— 端到端完整检测 3 种子合体评测与实测单图耗时帕累托分析**
   - **目标**：在同进程严格 FP32 方形 640 `COCO AP50-95 / AP50` 口径下，配对测试 `YOLOv8n (seed s)` × `分类器 (seed s)` (`s ∈ {0,1,2}`)，对比原生单阶段、无条件轻量两阶段（复现并解释为何朴素轻量两阶段失效）、低置信度门控、**`MGS-SymTex-Light`（端侧轻量档，3.35M 零增耗剪枝）** 与 **`MGS-SymTex-Pro`（高精度档）**，并在 RTX 4060 Ti 上实测单图端到端均值与 P95 延迟（ms）。

3. **实验 E3（`exp3_external_blind_validation.py`）—— 冻结模型跨数据集一次性零样本封口盲测**
   - **目标**：在所有模型权重与源 `val` 门控分位数阈值（`q=0.80`）完全冻结后，不改一行参数，在从未参与训练或选参的 4 个像素去重独立公开数据（《中文分类与标签使用索引.json》`索引去重保留=True 且 同库跨标签冲突=False`，与 `SciDB` 零像素重叠）上执行一次性零样本评测：
     - 外部真实果园带框检测集：`Zenodo 11148332 (orange_detection_COCO)`（`N=519` 张真实果园图、`1,766` 个经核验与缩放图严格对齐的归一化 YOLO 标注框；注：开跑前核验发现 GitHub `Citrus_Leaves.zip` 实为无框分类图，而本地已审计去重的 `orange_detection_COCO` 具备真实果园复杂背景叶框，依审计规范仅作症状级盲测：2 类健康/黄化病叶检测 + 3 类健康/斑驳黄化疑似/缺素对称黄化疑似检测与框分类，不宣称 PCR 病原真值）；
     - 外部独立叶片分类集 A：`Sweet Orange V1`（`f7cr74mwpj` 去重保留：`Healthy leaf` 547 + `Citrus canker` 588，共 `1,135` 张）；
     - 外部独立叶片分类集 B：`Zenodo 11148332 Citrus`（去重保留：`anthrax` 219 + `canker` 341，共 `560` 张）；
     - 外部跨树种叶片分类集 C：`Pomelo Leaf V2`（`vk7dnf8nrj` 柚叶原图子集去重保留：`Healthy` 241 + `Yellow Mosaic` 51，共 `292` 张）；
     - 外部受控掩膜集：`CitrusUAT`（共有类零样本分类 + 叶片前景掩膜 `Energy-Inside-Mask` 定量可解释性，已在 E1 同步输出）。
