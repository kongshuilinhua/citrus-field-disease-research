## 一、背景诊断与设计动机

### 1.1 前期单阶段改进连续阴性的实测归因
根据仓库 2026-10-26 至 2026-11-16 已完成的受控实验记录：
1. **源域同分布分类已近饱和**：在清理后 14 类 SciDB 源 `val`（866 张图 / 869 个真实框）上，原生 YOLOv8n 对匹配框的类别正确数已达 **862 / 869（99.19%）**，完整检测 `COCO AP50-95 = 90.6759%`（见 `方法路线扩展_20261031/66_像素完整检测阴性与端到端先导.md`）。即使替换为 DINOv2 大教师类别，在源 `val` 上也出现“纠错 4 个、误改 7 个”的净退步（`90.1112%`）。
2. **非穷尽标注边界限制**：源 `val` 中 `S2 Healthy leaf` 存在约 95～101 个高置信未匹配框落在同图真实可见的其他叶片上（见 `72_健康叶未匹配候选与标注范围问题.md`），导致标准 COCO 评测对同域检测的进一步刷分存在标注边界瓶颈。
3. **真正的性能鸿沟在跨条件与开放环境**：
   - 原生 YOLO11n / YOLOv8n 从源 `val`（`~90%`）跨到 `testB`（自然田间）与 `testC`（同对象白板背景）时，`AP50-95` 暴跌至 `67.50%~71.25%` 与 `68.65%~72.77%`；
   - 保持完全相同的检测提案框与分数，仅替换框内前景重分类（`35_两阶段重复结果与实际开销.md`），`testB / testC` 分别恢复 **+9.90pt / +15.38pt**，但全量重分类带来 **+76% 推理耗时**（`19.51ms → 34.36ms`）且损害源域精度；
   - 在 `CitrusUAT` 跨域评测中（`复现_baseline/eval_m0_crossdomain.py`），训练未见的 Fe/Mg/N/Zn 缺素黄化有 **89%–100%** 被闭集分类器误判为检疫性黄龙病（HLB）；
   - 单阶段直接引入 KL 蒸馏或 ROI 辅助时，探针实测存在 **39.60%**（标签一致组 33.78%、不一致组 77.80%）的局部梯度负内积冲突（`47_源训练梯度冲突探针结果.md`）。

### 1.2 大小论文弹性拼装总架构
将候选创新拆解为流水线上的 **前（P1）、中（P2）、后（P3）三个正交模块**，通过低成本探针逐一检验，择优保留：
- **核心小论文**：取探针筛选中增益最显著、消融最干净的 1 个核心模块（或 `P2+P3` 紧凑协同），补齐 3 随机种子 + 1 个未见公开集盲测独立成文。
- **硕士学位大论文**：
  - 第三章：复杂果园病叶检测的场景解耦与非穷尽标注误差机理（对应模块 P1 / 路线 B）；
  - 第四章：面向易混症状的叶片对称拓扑—微观病斑跨场景表征学习（对应模块 P2 / 路线 C）；
  - 第五章：风险校准选择性级联、层级证据开放集拒识与端侧轻量化部署（对应模块 P3 / 路线 A + 胡柚落地验证）。

## 二、统一数据集分工与防泄漏红线

1. **SciDB 统一清理版 14 类（`train 7136 / val 866`）**：唯一主训练集；源 `val` 用于早停选轮、超参选择与**同域不退化约束**（不再要求在 99.2% 分类饱和区强行涨点，要求同域 `AP50-95` 不发生实质退步）。
2. **SciDB 同对象跨背景诊断集（`testB 602 / testC 602`）**：历史条件探索与跨背景机理剖析集（按 602 个配对对象统计 `AP50-95` 与跨背景预测翻转率 Flip Rate）；**严禁用于调参或选最佳轮次**。
3. **CitrusUAT（`953张`，深灰底受控单叶 + 二值掩膜 + qPCR HLB + 5种缺素）**：严禁混入训练；承担 ① 严格对齐共有类零样本分类评测、② 5种未知缺素误判为 HLB 的开放集假阳性率（FPR）评测、③ 真实叶片二值 Mask 内的注意力集中度（Energy-Inside-Mask）定量评测。
4. **独立公开外部盲测集（预留 `Zenodo 11148332` 或 `Sweet Orange V1` 原图共有类）**：开发期物理隔离，方法冻结后仅执行一次零样本盲测。
5. **常山胡柚自采图（`190张` + 待补采）**：无农技专家确诊真值前**严禁报告准确率**，仅用于不确定性预警率统计与定性案例展示。

## 三、三路线 Phase 0 低成本探针筛选协议

### 3.1 探针 A（路线 A / 模块 P3）：风险校准选择性路由 + 病理层级证据开放集诊断
- **待验证假设**：
  - H-A1：目标框在特征空间的源域马氏距离/能量分歧与预测熵可有效区分“源域已正确框”与“跨场景退化错判框”，实现在低触发率（如 ≤30%）下消除源 `val` 误改负收益并保留 `testB/C` 绝大部分重分类增益；
  - H-A2：引入“黄化簇/坏死斑簇/健康”病理层级约束的狄利克雷证据网络（Hierarchical EDL），可在保持已知病害分类精度的同时，大幅降低 `CitrusUAT` 未知缺素误判为黄龙病（HLB）的假阳性率。
- **最接近工作**：无条件两阶段重分类（本项目 `35_`）、MSP/Energy 开放集检测、标准 Evidential Deep Learning（Sensoy et al., NeurIPS 2018）。
- **本方案改动**：将“无差别全量重分类”升级为“分布偏移感知的风险校准选择性级联”，并将扁平 EDL 升级为融合柑橘植保表观层级树的层级证据不确定性诊断。
- **继续/暂停判据**：
  - **支持继续（Go）**：源 `val AP50-95` ≥ 原生基线（消除 `-0.34pt ~ -0.56pt` 误改损失），同时以 ≤40% 的精细分支触发率保留全量两阶段在 `testB/C` 80% 以上的净增益；且未知缺素→HLB 误判率相对普通交叉熵头降低 ≥30 个百分点。
  - **应当暂停（Stop）**：门控对错框/跨域退化框的区分 AUROC < 0.65，或 EDL 严重损害已知类准确率（下降 >2pt）。

### 3.2 探针 C（路线 C / 模块 P2）：叶片双侧非对称拓扑—微观高频病斑动态协同表征
- **待验证假设**：
  - H-C1：针对黄龙病“跨中脉不对称斑驳”与缺素症“沿脉对称黄化”、溃疡病“局灶隆起斑”的病理差异，显式构造双侧特征非对称差分流与高频纹理残差流，并通过熵驱动门控动态融合，在跨背景（`Test B↔C`）与跨源（`CitrusUAT`）上优于普通单流及简单局部-全局拼接。
- **最接近工作**：多尺度/全局-局部拼接分类器（GPT 建议 B4）、DINOv2 CLS+patch 拼接（本项目 `基线补齐_20261026`）。
- **继续/暂停判据**：
  - **支持继续（Go）**：在同一轻量骨干下，黄化易混子类 Macro-F1、`Test B↔C` 同对象一致性及 `CitrusUAT` 共有类准确率同时优于单流基线与普通拼接对照（≥ +1.0pt），且真实叶片 Mask 内注意力占比提升。
  - **应当暂停（Stop）**：与普通拼接差距 < 0.5pt。

### 3.3 探针 B（路线 B / 模块 P1）：框条件场景正交解耦 + 正交梯度投影的无冲突单阶段检测泛化
- **待验证假设**：
  - H-B1：利用 SciDB 训练集中自然果园背景与受控背景板的共存特性对分类特征施加场景正交解耦，并对跨模型关系蒸馏梯度实施相对原生 BCE 梯度的正交投影（消除 `47_` 实测的 39.6% 负内积冲突），可在零推理额外开销下保持源 `val` 不退化并显著提升 `testB/C` 检测 `AP50-95`。
- **最接近工作**：普通正匹配软 KL（`44_`）、端到端 ROI 特征对齐（`75_`）、PCGrad（Yu et al., NeurIPS 2020）、RKD（Park et al., CVPR 2019）。
- **继续/暂停判据**：
  - **支持继续（Go）**：梯度探针负内积冲突消除，单种子 `seed=0` 30 轮源 `val AP50-95` 波动在 `-0.2pt` 内，且 `testB` 或 `testC` 提升 ≥ `+2.0pt`。
  - **应当暂停（Stop）**：`testB/C` 净提升 < `+1.0pt`（受限于轻量检测头容量，立即停止单阶段内部损失探索）。
