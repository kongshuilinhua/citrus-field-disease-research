# 项目历史索引

> 本文件是可迁移的“项目历史记忆”入口。它不替代原始报告，只提供时间线、关键变化和证据链接。最后更新：2026-09-09。

## 阅读优先级

当不同文档出现冲突时，按以下顺序判断：

1. `USER_REQUIREMENTS.md`：用户当前明确诉求。
2. `DECISIONS.md`：已确认决策和长期不变量。
3. `PROJECT_STATE.md`：当前经过协调者验收的状态。
4. `CURRENT_ROUND.md`：当前任务、状态、范围和下一步。
5. `reports/`：每次研究和实施的证据。
6. `docs/`：历史交接、方案、调研和实验汇总。

旧文档是历史证据，不因较早创建就自动成为当前结论。

## 2026年9月9日：公司数据规范

- 老师将协助向公司索取数据，当前优先交付物转为现有图像数据提供清单。
- 第三轮生成的原始需求单过于复杂，并包含1000～1500张、缺素主采、强制PCR及由研究方提供App等未经确认内容，未被采纳。
- 进一步确认当前是索取公司已经拥有的数据，而不是先制定未来采集配额；现有相关图片不限定种类、数量、拍摄方式和标注完整度，先全部接收再筛选。
- 公司不需要补画框、掩膜或补齐缺失信息；已有标签和说明有则一并提供，无PCR时黄龙病不设确诊类。
- 另形成独立App数据要求，固定 `sample_id`、`image_id`、类别版本、复核状态、离线重试、幂等上传和完整导出规则，不作为现有图片的提供门槛。
- 用户再次纠正：索取范围仅限胡柚、香柚，不包括其他柑橘。此前扩大物种范围的修改无效。已恢复原版独立文件；修改稿保留为待确认，不代表验收通过。
- 原版：`docs/data-requirements-向公司交付-胡柚病虫害数据.md`；待确认稿：`docs/胡柚香柚现有图像数据提供清单_待确认.md`。

## 当前最新结论

- 纯净背景分类不是主线。
- 第一阶段同时比较单器官分类＋弱定位和患病器官/病斑检测，最终任务等待先导数据确认。
- 公开柑橘用于预训练和迁移，胡柚/香柚负责目标微调与独立测试。
- 不预设YOLO或非YOLO赢家。
- 当前最值得优先验证的是背景/来源域鲁棒性；分类—定位解耦仅在检测路线成立后验证。
- 数据标签审计仍未完成，方法方案和正式实验尚未解锁。

## 如何继续追加历史

每个Agent只新增独立报告。协调者验收后：

1. 更新 `PROJECT_STATE.md`；
2. 必要时更新 `DECISIONS.md` 和 `USER_REQUIREMENTS.md`；
3. 在本文件追加一条时间线；
4. 更新 `CURRENT_ROUND.md` 中的Agent状态和下一道门。
