# 项目历史索引

> 本文件是可迁移的“项目历史记忆”入口。它不替代原始报告，只提供时间线、关键变化和证据链接。最后更新：2026-11-19。

## 阅读优先级

当不同文档出现冲突时，按以下顺序判断：

1. `USER_REQUIREMENTS.md`：用户当前明确诉求。
2. `DECISIONS.md`：已确认决策和长期不变量。
3. `PROJECT_STATE.md`：当前经过协调者验收的状态。
4. `CURRENT_ROUND.md`：当前任务、状态、范围和下一步。
5. `reports/`：每次研究和实施的证据。
6. `docs/`：历史交接、方案、调研和实验汇总。

旧文档是历史证据，不因较早创建就自动成为当前结论。

## 2026年9月20日：SciDB 三条件补测

- 用 2026-07-26 的 YOLOv8n 权重不训练、不调参补测 testB/testC，并复算 testA。
- testA mAP50 复算与历史逐位一致（92.3633025%），确认权重、类别映射与评估流程一致。
- testA/testB/testC 的 mAP50 为 92.36% / 85.72% / 84.99%，mAP50–95 为 85.27% / 77.64% / 80.14%。
- 结论：主要瓶颈是分类而非定位，定位覆盖率均 ≥98.3%，B/C 类别错误是 A 的 2.7/3.3 倍。
- 190 张胡柚外测无真值，仅作域偏移参考。
- 证据：`reports/2026-09-20/scidb-abc-补测与胡柚外测.md`。

## 当前最新结论

- 纯净背景分类不是主线；实际主线为复杂田间检测 + 可靠性。
- 主要瓶颈是分类而非定位；误差集中在视觉相近类别对。
- 检测矩阵机制：能否修好 S12 取决于是否逐目标建模，不是骨干。
- 可靠性机制成立，但不能断言"哪个架构净增益最高"。
- 公开数据方法改进至今全部阴性，尚无原创方法成立。
- B/C 是同对象历史探索集，不是独立验证。
- 胡柚专家真值与设备配对数据仍缺，不报告胡柚准确率。
- 下一步为结果到主张判读与证据复用核查，训练性实验 blocked。
