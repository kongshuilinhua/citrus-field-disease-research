## 当前判断

1. 实际研究主线已是**复杂田间目标检测 + 可靠性（拒识与候选复核）**；分类降为辅助与部署形态。
2. 干净背景分类约 95%—96% 已饱和，继续刷同域准确率没有价值。
3. SciDB 三条件基线可复现：testA/testB/testC 的 mAP50 为 92.36% / 85.72% / 84.99%（2026-09-20 补测）。
4. **主要瓶颈是分类而非定位**：三组定位覆盖率均 ≥98.3%，testB/testC 的类别错误是 testA 的 2.7 / 3.3 倍。
5. 检测矩阵机制结论较稳定：能否修好 S12 藻斑这类系统性缺陷，取决于是否对每个目标单独建模（RoI 裁剪或 object query），不是骨干或具体实现。
6. 可靠性机制成立：三信号融合 AUC 0.887/0.895，拒识 15% 净增益 +7.92/+7.50；但不可断言"哪个架构净增益最高"。
7. 2026-10-27 起的方法改进尝试（QFL、几何对照、ROI 辅助、轻量像素学生、冻结 ROI 小头、监督筛选、硬目标/普通 KL）**尚无一项稳定超过强基线**（源 val AP50–95 = 90.6759%）。
8. 胡柚准确率仍无专家真值；设备差异问题用现有数据无解。

## 用户确认的应用条件

以 `coordination/USER_REQUIREMENTS.md` 为准，要点：

- 目标对象为胡柚与香柚；范围为病害和虫害，缺素等非生物胁迫不作为主要识别类别，但可作未知/OOD 测试。
- 复杂果园背景是正式场景，App 近距离拍摄但不能保证画面只有一个器官。
- 标注应尽量简单；农民可初标，专家可复核；不要求公司人员画框或掩膜。
- 黄龙病没有 PCR，不作为确诊类别；黄化不等于黄龙病。
- 公开柑橘数据仅作辅助训练，必须保留来源域并在目标品种上微调、独立测试。
- App 端或服务器端推理尚未确定，不能提前锁死模型大小。

## 已确认的技术决策

- 主任务为检测，主指标 AP50–95 与 AP50 同时报告，固定框分类正确率单独报告。
- 至少三个随机种子，逐种子报告并分析不确定性；平均值略高不足以判定稳定提升。
- 预冻结数据划分、主指标、比较方法、训练与选参预算；B/C 不参与选参。
- 改进必须与普通微调、已有适配方法和相关简单方法比较，不能只超过弱冻结头。
- 基线复现与组件组合不自动等于原创贡献；失败与负结果必须留档。
