## 当前判断

1. 研究主线仍是**复杂田间检测 + 可靠性**，但 11-23/24 的证据把问题定位得更细：**损失的大头在定位与未输出，不只分类**。
2. 固定框、只换框外背景：testB 486→390（−15.9 点）、testC 434→319（−19.1 点）；等面积对照接近 0，说明不是任意像素扰动。
3. 但相对“框外置灰”，多出来的损害里分类只占 36%–55%，其余是定位丢失与未输出；预注册判据 C 未通过，**分类一致性消融（第二阶段）不启动**。
4. 位置对照（near vs far）目前做不干净：严格合格 9/96，70% 接缝不平衡，testC s96 为 0/24，且**没有可用前景掩膜**。
5. **病原学复核应按类条件风险排序，而不是按置信度**：置信度在 5% 预算只捕获 3.7%（随机 5.4%），类先验在 5%/10%/20%/30% 预算为 22.9%/33.0%/59.6%/74.3%，是随机的 2.5–4.6 倍。
6. **约 100 条带 PCR 的校准样本**即可拿到渐近收益的约 91%，这是当前最便宜、最有证据的一步。
7. 190 张自采图：多叶常见（158 张 4+），但目标不明少见（9 张多目标）；对象簇 161、采样隔离簇 148，不能当 190 个独立对象；专家盲评 0 份回填。
8. 公司照片本轮 0 张可访问；品种、地块、许可全部未确认。

## 已确认的技术决策

- 主指标 AP50–95 与 AP50 同时报告，固定框分类正确率单独报告，不混用。
- 至少三种子；单种子结果只能写“初步”。
- 预冻结划分与预算；B/C 不参与选参。
- 预注册判据不得在看到结果后修改；判据未通过即停止，不追加模块。
- PCR 只作分析真值，不进入训练与选参。
- 失败与负结果必须留档；负结果不得改写成“有希望”。
- 不同 GT 来源与评估脚本的数字不得拼接比较。
