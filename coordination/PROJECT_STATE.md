# 项目当前状态

> 此文件是中央状态源，只由协调者根据已验收报告更新。最后更新：2026-09-05。

## 当前判断

1. 干净背景柑橘叶分类约95%—96%，继续刷同域准确率价值有限。
2. 跨数据集表现差异明显，轻量模型存在域鲁棒性问题。
3. 缺素和黄化会被闭集模型误判为黄龙病，可靠性评估不可省略。
4. SciDB YOLOv8n检测基线 mAP50 为92.3633%，普通YOLO模块改造不宜作为默认主线。
5. 190张胡柚自采图以田间单叶/单果近景为主，适合分类、病斑定位或分割，不适合把“框出整片叶子”作为主要贡献。
6. 未标注只代表需要标注流程，不等同于必须采用无监督方法。

- App近距离拍摄为主，但不能保证只拍入一个叶片或果实，复杂果园背景是正式场景。
- 目标范围为病害和虫害，缺素等非生物胁迫不作为主要识别类。
- 预计约1000张，当前190张仅用于场景参考，不保证进入最终训练。
- 标注形式可按研究需要设计，但应尽量简单；农民可初标，专家可复核。
- 黄龙病没有PCR，不作为确诊类别。
- 面向胡柚和香柚；公开其他柑橘数据希望用于辅助训练，但必须保留来源域并在目标品种上微调、独立测试。

## 当前暂定推荐（等待数据Agent与先导实验确认）

- 第一阶段优先采用“患病器官级bbox”：框受害叶片或果实并标类别，不要求全量病斑掩膜。
- 统一比较YOLO、Faster R-CNN和RT-DETR，不预设最终骨干。
- 主研究候选是多源柑橘迁移与前景—背景解耦；20%—30%近景—稍远配对可作为高潜力扩展。
- 最终类别在目标果园调查后锁定4—6类，每类按唯一症状对象计数，黄龙病保持疑似/unknown。
- 详细证据和方案见 `reports/2026-09-05/research-direction-v1.md`。
