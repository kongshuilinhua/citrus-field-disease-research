## 二、已完成的结果

### 1. 分类基线（Mendeley 5类，干净背景）
EfficientNet-B0 95.80%/宏F1 97.28% · ResNet50 95.80%/97.25% · MobileNetV3 94.96%/96.74%。
→ 干净背景已饱和；唯一系统错误 black_spot↔greening。详见 `复现_baseline/复现报告.md`。

### 2. M0 跨域掉点（干净模型 → CitrusUAT orange 异域）
重叠类严格5类：EffNet-B0 **22.4%** / ResNet50 82.5% / MobileNetV3 49.0%。
缺素黄叶被误判成 HLB（MobileNetV3 上 Fe92%/Mg89%/N100%/Zn95%）。详见复现报告第九节。

### 3. [35] DANN 域适应（忠实重实现 MSUN 思想）★
源域 Mendeley(有标签) → 目标域 CitrusUAT(无标签)，同架构同轮数对照：

| | 严格5类 | 2类(healthy/greening) |
|---|---|---|
| source-only(≈M0) | 22.4% | 30.1% |
| **DANN 域适应** | **79.7%** | **87.4%** |
| 提升 | **+57.3pt** | **+57.3pt** |

→ 无监督域适应几乎补回全部跨域掉点，忠实复现 MSUN 核心主张。日志 `results_dann/dann_log.txt`。
