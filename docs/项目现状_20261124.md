# 项目现状（2026-11-24 更新）

> 本文取代 `docs/项目现状_20261122.md`，旧版保留为历史。
> 11-23/24 的工作以**预注册 + 探索性分析**为主：没有训练新模型、没有改权重、没有用 PCR 训练或选参。所有结论的定位都是 development，不是独立验证。

## 一、一句话现状

这三天把“背景/上下文到底影响哪一步”拆清楚了：**固定框、只换框外背景，确实让检测判定大幅下降（−12 到 −19 点），但相对既有的“框外置灰”，多出来的损害主要落在定位与未输出，而不是分类**。按预注册判据，分类一致性消融（第二阶段）**没有启动**。同时，病原学评估给出了一个更可做的方向：**按类条件风险排序送审，而不是按置信度**，并且约 100 条带 PCR 的校准样本就能拿到九成收益。

## 二、新增结果（11-23 至 11-24）

### 2.1 上下文干预第一阶段（预注册，已停止）

| 条件 | testB 常规 | testC 常规 |
|---|---:|---:|
| D0 原图 | 486（80.7%） | 434（72.1%） |
| D1 框外置灰 | 462（76.7%） | 414（68.8%） |
| D2 框外真实背景替换 | **390（64.8%）** | **319（53.0%）** |

- D2 的损害显著且方向一致；D3 接近 0，说明**不是“动像素就会变”**。

- 预注册判据 C（D2 翻转集与 D1 重叠 < 50%）实测 54.3% / 52.7%，**未通过 → 第二阶段不启动**。

### 2.2 检测归因诊断：563 个失败样本的去向

对 D0 正确、D2 失败的 563 个样本拆解：

| 去向 | 占比 |
|---|---:|
| 分类被改（有框但类别错） | 40.1% |
| 低阈仍有框但类别错 | 11.2% |
| 目标彻底丢失 | 24.9% |
| 排序/候选问题 | 23.8% |

- donor 抢分不是主因：337 个可判定样本中 50 例（14.8%），且 50 例里 donor 与原因同类仅 3 张。
- 归档：`docs/experiments/检测归因诊断_20261123.md`。

### 2.3 等面积位置先导：位置对照目前做不干净

- 严格合格只有 **9/96 个“图×尺寸”（8 张唯一图）**；testC 的 s=96 为 0/24。
- **70%（35/50）的几何+donor 案例接缝不平衡**：同面积、同周长不等于同接缝强度。
- donor 清洁度是 testC 的主瓶颈；自动绿/边筛查会漏黄绿叶、手指、橙红果。
- testB/testC **没有可用的逐图前景掩膜**，所以“只改背景、不动目标”不成立。
- 结论：可以做小规模位置对照先导（9 个合格样本），但**不能据此证明位置效应**；要扩样必须先解决掩膜或 donor 选择协议。
- 归档：`docs/experiments/等面积位置先导_20261123.md`。

### 2.4 病原学层面评估：复核该按什么排序

| 项 | G1（斑驳/红鼻/明脉/均匀黄） | G2（G1 + 缺锌） |
|---|---:|---:|
| 症状标签灵敏度 | 75.2% | 91.2% |
| 模型灵敏度 | 67.2% | 82.5% |
| 模型特异度 | 86.1% | 80.0% |

- 模型基本继承标签的病原学行为，**没有引入超出症状标签的判别力**。
- 109 个病原学错误里 FP 64、FN 45；“无输出”39 张中只有 5 张 PCR+，不是可疑病例富集池。
- **按置信度送审在低预算下不如随机**（5% 预算捕获 3.7% vs 随机 5.4%）；两模型分歧同样无效。
- **按预测类别的历史病原学错误率排序**，5 折交叉拟合在 5%/10%/20%/30% 预算捕获 22.9%/33.0%/59.6%/74.3%，是随机的 2.5–4.6 倍。
- 校准样本量曲线：**约 100 条带 PCR 的校准样本**可拿到渐近收益的约 91%，200 条后边际很小。
- 归档：`docs/experiments/病原学层面评估_20261123.md`。

## 四、能说 / 不能说

**能说**

- 框内像素不变、只换框外真实背景，检测判定显著下降（−12 到 −19 点），两套权重、两个方向一致。
- 该效应不是任意像素扰动：等面积对照接近 0。
- 损失中相当一部分来自定位与未输出，不只分类。
- 病原学复核按“类条件风险”排序远优于按置信度；约 100 条 PCR 校准样本即可。
- 190 张自采图“多叶常见、目标不明少见”，且不能当 190 个独立对象。

**不能说**

- 不能说这是独立验证或部署性能（testB/C 是历史探索集，参考框来自发布者标注）。
- 不能说“背景是因果原因”（无掩膜，存在接缝与 donor 干扰）。
- 不能说“位置效应已被证明”（位置先导只做了可行性，未跑模型）。
- 不能说“类先验方法已验证”（仍是同一数据集内交叉拟合）。
- 不能把“未见明确病征”当健康，也不能声称专家已复核。
