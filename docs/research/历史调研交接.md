## 1. 项目背景与人物

- 用户身份：计算机专业研究生。
- 研究方向：**柑橘病虫害检测**（图像方向）。
- 当前阶段：前期调研。正在汇总他人方法与数据集，以此构建自己的方法。
- 关键约束：
  - 任务倾向**图像分类**（尚未完全锁定，后期可能升级到检测/分级）。
  - **暂无自有数据集**；后期可能拿到**合作果园的田间数据**（重要变量）。
- 工作目录：`新版柑橘`（即本文件所在文件夹）。

---

## 2. 研究方向讨论的结论

经讨论，给出的推进逻辑：

1. 分类是合理起点，门槛低、能快速建立领域直觉；待果园数据到位再升级到检测/分级。
2. 调研要分清任务类型（分类 / 检测 / 分割 / 严重度分级），并对数据集逐项记录（规模、类别、标注、实验室 vs 田间、公开性）。
3. **最大痛点 = Lab→Field 域差距**：实验室干净背景数据训练的模型，用到田间精度掉 30–40%（文献实证 99%→42%；跨果园 98%→50–88%）。这与用户"实验室预训练 + 后期果园田间数据"的节奏天然契合，是首选研究方向。

### 3.3 联网补充的高质量论文（24 篇，专业站点）

来源覆盖 arXiv / IEEE / ScienceDirect / Springer / MDPI / Nature / Frontiers。最有价值的几组：

- **域适应 / 跨数据集迁移（★★★，支撑首选方向）**：背景重组UDA、域泛化Lab→Field、TransConv+Wasserstein DA、Few-shot度量DA、柑橘跨数据集迁移学习HLB检测（CEA 2025, S0168169925009925）。
- **柑橘田间检测**：DCH-YOLO11（自然田间黄龙病，MDPI Math 2025）、YOLOV8-CMS（分类+分级，黄龙病99.4%，13.4MB移动端）。
- **前沿自监督/细粒度**：柑橘聚类对比表示学习（arXiv 2507.11171）、PSMamba（叶脉级细粒度）、ConMamba（对比Vision Mamba）。
- **田间光谱**：ASTransformer（手持光谱仪，可区分缺素 vs 病害）。

### 3.5 每篇论文的数据集来源（已填入索引 J 列）

实查 28 篇柑橘论文原文后得出：

- **真正用公开数据集的仅 3 篇**：EfficientNetB5(Kaggle)、Cetiner(Citrus Leaves=Mendeley)、害虫服务系统(部分Kaggle/Citrus Image Gallery)。
- **CitDet、PDT 本身即公开数据集**。
- **其余绝大多数为自采/自建**，尤其**所有高光谱/UAV论文均为自采且未公开**（柑橘领域无公开高光谱/UAV数据集）。
- 3 篇 RGB 论文原文未讲清数据来源，已标"待核"。

> 这一结论本身印证了研究空白：**柑橘田间/光谱数据稀缺 → 做"田间新基准"含金量高。**

## 4. 研究空白与建议方向（来自"研究空白"工作表）

| 优先级 | 缺口 | 可行方向 | 与用户数据匹配度 |
|---|---|---|---|
| ★★★ | Lab→Field 域差距(掉点30-40%) | 实验室预训练+少量田间样本域适应/小样本 | 高(契合后期果园数据) |
| ★★★ | 公开柑橘田间数据少、背景单一 | 构建田间柑橘新基准(分类+检测) | 高 |
| ★★ | 黄龙病早期/无症状/缺素混淆 | 细粒度+多模态(RGB+光谱)早期识别 | 中 |
| ★★ | 多模态融合在柑橘仅少量工作 | RGB+多/高光谱轻量融合 | 中 |
| ★★ | 数据稀缺/长尾病害 | 小样本/自监督/生成增强 | 中 |
| ★ | 田间实时/边缘部署轻量化 | 轻量骨干+压缩 | 中 |
| ★ | 病虫害时序预测在柑橘少 | 气象+影像预测发病 | 低-中 |

**建议的前期动作（拿到果园数据前即可推进）：**
1. 下载 Mendeley + TFDS 跑通 2–3 个 baseline（ResNet/EfficientNet/一个 ViT），建立自己的代码框架与对照系。
2. 按索引读 15–20 篇近两年论文，填满方法表，重点读蓝色"域适应"那一组。
3. 做预实验验证跨域掉点确实存在（用 Mendeley 训练 → 在另一来源/田间图测试）。

## 6. 交接给下一个模型时要知道的"坑"

1. **Excel 文件锁**：若用户在本地 Excel 打开该文件，写入会报 `PermissionError/LOCKED`，需先让用户关闭文件再写。
2. **挂载盘禁止删除目录**：`rmdir`/删除空文件夹会 `Operation not permitted`；只能移动/重命名文件，不能删目录。
3. **不要轻信搜索摘要里的数据集数字**——此前 Kaggle"7500/7类"就是搜索引擎把不同数据集混淆所致，正确是 607/5类。涉及数据集事实务必访问一手来源核验。
4. **数据集去重**：Mendeley / TFDS citrus_leaves / Kaggle那个 是同一数据，勿当不同集重复引用。
5. **PDF 无法自动下载**：出版商站点 PDF 是二进制，工具只能取文本，不能落地保存；新论文需用户手动下。
