## §1 真问题（四交叉空白）

| | 跨品种(橙→胡柚) | 复杂田间 | 纯RGB/手机 | 小样本 |
|---|:-:|:-:|:-:|:-:|
| 全库现状 | 仅 #22/#24/#45，**全靠光谱** | 有 | 有 | 少数 |
| **你的场景** | ✓ | ✓ | ✓ | ✓ |

> 在**仅手机 RGB、单张 4060、目标域(胡柚)自采稀少**下，打通"公开橙橘干净 → 常山胡柚复杂田间"的**双重域差(跨品种 + Lab→Field)**。全库碰"跨品种"仅 3 篇、全靠光谱，**纯 RGB 跨品种 = 0 篇**。

## §2 选型公理（带出处，防缝合）

1. 目标域数据少 → **不上重型 UDA**（#35 前提"大量无标签目标域"我们不满足）→ 走自监督+少样本(#55/#56)或域泛化(#27)。
2. 视觉域差 → **FBR + 条件对抗**(#26 证真实田间 CORAL/MMD 失效、只 CDAN+E 有效 47→91)。
3. 背景重组是**辅助**、对抗 UDA 才是主力(#26 消融：仅 FBR +9.9、仅 UDA +41.3)。
4. 跨品种差距**可控**(#22：20 张/类微调即 90%+)→ 走少样本微调、不上天顶方法。
5. 纯 RGB 跨品种 = 研究新意锚点(全库空白)。
6. 落地轻量化有成熟件：蒸馏 #65/#67(Jetson/树莓派实测)、13.4MB #28。

## §3 数据与标注通则（所有方案共用，先看这节）

### 3.1 数据三角色
| 角色 | 是什么 | 从哪来 | 要不要自己标 |
|---|---|---|---|
| **源域** | 公开橙橘/柑橘，干净背景 | Mendeley叶609、4类柚叶1090、PlantVillage、福建SciDB | **不用标**(现成) |
| **目标域** | 常山胡柚/香柚，真实果园复杂背景 | 自采 | 看方案：零/无标签/少量 |
| **测试集** | 胡柚真实分布 | 自采中划出 | **必须标**(评估) |

> 你的标注量 = 目标域 + 测试集；**源域全免标**。这块能压多小，取决于选哪套方案。

### 3.2 采集 SOP（可打印带去果园）
- **时间**：7 月夏梢(溃疡高发)；有条件 9–10 月补(炭疽/疮痂)。**设备**：手机 RGB，固定一台。
- **两版拍摄(关键)**：同片病叶拍 (a)贴近干净版 +(b)挂枝复杂背景版 ×2–3 角度 ≈ 5–6 张/叶。这两版的差=你要打的域差。
- **类别优先级**：★★★ 溃疡、健康(对照)；★★ 炭疽、缺素黄化；★ 疮痂；**黄龙病不现场判**(需 PCR，靠公开集)。
- **元数据(每张/批记)**：品种、地点、日期、光照、树龄、是否施药。
- **病名确认**：拿不准的标"待确认"、交农技/植保核；**错标比不标更坏**。
- **产出估算**：一人半天原图 300–600 张 → 筛后**有效 150–300 张**；凑齐"健康+溃疡各 200+"约 **2–3 个半天**。

### 3.3 标注工作量单位成本
| 标注类型 | 用于 | 单位耗时 | 1000 张≈ |
|---|---|---|---|
| 整图分类 | 分类方案 | ~10 秒/张* | ~3 小时 |
| 检测框 | 检测方案 | 30–60 秒/张 | 8–16 小时(1.5–2.5 人天) |
| 分割掩膜 | 严重度 | 手工 2–5 分；**SAM 半自动 30–60 秒** | 手工 4–10 人天；半自动 8–16 小时 |

> \*分类"10 秒"是病名**已定**后的纯打标签；真瓶颈在"**确认这是什么病**"(溃疡/炭疽/缺素易混)。→ 锚定"健康+溃疡"省的就是这块隐性成本。

### 3.4 省力 6 条
① 源域全用公开(免标)；② 优先免标方案(R1零标注/R2·R3无标签)；③ 锚定"健康+溃疡"省病名判别；④ FBR/生成造复杂背景样本省采集；⑤ 分割/检测走 SAM 半自动+主动学习；⑥ 分类起步(标注是检测的 1/5、分割的 1/10)。

### 3.5 待现场/导师确认（定了方案才能锁死）
1. 常山这片园**今年实际有哪些病**(有没有溃疡、炭疽)？2. **能采几次、谁一起采**？3. **谁帮确认病名/标注**？4. 要不要**检测/严重度**(标注翻几倍)？5. **无人机**(C2)拿不拿得到？

## §4 十二套方案卡

> 每套「数据·采集·标注」= 源/目标数据 + 需自采几个半天 + 标注类型与**人天**（单价见 §3.3，采集规范见 §3.2）。

### 落地档（公司向）

**L1 · 手机端胡柚病害分类器（自监督预训练 + 少样本微调）**
- **定位**：研究★ / 落地★★★ / 周期 3 月 / 4060 富余。
- **要解决什么**：常山胡柚自采量小，从零训会过拟合；公开橙橘虽多但品种/背景与胡柚有差。思路=用公开数据**自监督预训练**学通用病征表示 + **少量胡柚微调**绕开标注瓶颈，做一个手机能跑、在常山园好用的分类器。
- **数据·采集·标注**：源=公开橙橘/柑橘(Mendeley 叶609 + 4类柚叶1090 + SciDB，**无标签即可喂自监督**)；目标=自采胡柚 健康/溃疡各 100–200(可加炭疽)；测试=胡柚留出 ~150。**采集 ~2–3 半天；标注 ~2–4 人天**(整图分类，瓶颈是确认病名，见 §3.3)。FBR 把公开橙橘叶贴常山背景合成复杂样本，免额外采集。
- **方法(分步)**：
  1. **自监督预训练**([#55])：公开橙橘/柑橘(无标签)上用 SimCLR/BYOL 预训练 MobileNetV3-Large——对比两个增广视图学"病斑纹理/叶片结构"通用表示，不用标签，建立迁移基础。
  2. **少样本微调**([#56])：预训练 backbone 上用监督对比 + 近邻中心分类做少样本微调；类不均衡用 Focal Loss / 重采样。
  3. **FBR 数据桥**([#26])：SAM 中心点抠公开橙橘叶→形态学精修 mask→贴常山果园背景→合成"复杂背景橙橘"混入训练，补自采复杂样本不足。
  4. **轻量化落地**([#65/#67])：EfficientNet-B3 当教师蒸馏 MobileNetV3 学生 → INT8 量化导出 TFLite → 拍照 demo(病种+置信度+建议)。
- **实验设计**：baseline=ImageNet 直迁；对照=ImageNet vs 公开柑橘自监督预训练(证自监督价值)；消融=有无 FBR、有无少样本策略；指标=Acc/宏F1/各类F1 + 模型大小/手机端延迟 FPS。
- **算力**：MobileNetV3-Large，输入224，batch64，混合精度，显存 <4GB；自监督预训练几小时~1天，微调快。
- **里程碑**：7月 公开集自监督预训练 + 去常山采集；8月 少样本微调 + FBR 扩样 + 调优；9月 蒸馏量化 + 手机 demo。
- **风险→对策**：自采不足→FBR+少样本兜底；病种不重合→锚定"健康+溃疡"起步；新意弱→靠"跨品种+复杂背景真实落地+数据桥"讲工程故事。
- **价值**：落地=常山胡柚园可用手机识别器(<10MB)；研究=偏应用，可小结"自监督预训练对跨品种落地的增益"。

**L2 · 手机端分类 + 严重度分级**
- **定位**：研究★ / 落地★★★ / 周期 3–4 月 / 4060 够。
- **要解决什么**：植保不止要知"什么病"，还要"多重"才能决定打不打药、打多少。在 L1 之上加严重度分级，交付更实用。
- **数据·采集·标注**：同 L1 + 溃疡病斑**掩膜**数百张(定级用)；采集同 L1；**标注 = L1 的 2–4 人天 + 掩膜(SAM 半自动)~2–4 人天**。
- **方法(分步)**：
  1. **病种识别**：直接用 L1 分类器定"是不是溃疡/健康"。
  2. **叶片分割去背景**([#58])：先从复杂背景抠出叶片区域(YOLOv8-seg-n 或 SAM)，#58 证"先去背景"能把病斑分割 F1 提 5+ 点。
  3. **病斑分割 + 定级**([#28])：在纯叶片上分割病斑→算"病斑/叶面积比"→按阈值分轻/中/重(阈值与农技共定)。
- **实验设计**：分类指标同 L1 + 分级 F1/MAE；消融=有无"先抠叶去背景"(复刻 #58 的提升)。
- **算力**：分割用轻量 U-Net / YOLOv8-seg-n，4060 够。
- **里程碑**：在 L1 基础上 +1 月做分割分级 + 阈值标定。
- **风险→对策**：掩膜标注贵→只标溃疡一类、SAM 预标+人工修；分级阈值主观→跟农技对齐、给参照图。
- **价值**：落地=带严重度的植保工具(公司更认)；研究=严重度量化方法。

**L3 · 边缘盒子 / 巡检检测**
- **定位**：研究★ / 落地★★★ / 周期 4 月 / 4060 够(训练)。
- **要解决什么**：手机拍照是"人找病"，果园大时效率低。改成固定点摄像头或巡检车上实时**检测**，模型自动在画面里框出病叶——面向规模化巡园。
- **数据·采集·标注**：源=公开橙橘；目标=SciDB/#36(12病)/#7(9219图含溃疡)田间检测集 + 自采，**逐框标 bbox**；采集 ~3–4 半天；**标注 ~4–8 人天**(检测框最贵，见 §3.3)。
- **方法(分步)**：
  1. **检测器**：YOLO11n / YOLOv8n(轻量、适合边缘)，田间集上训。
  2. **小目标增强**([#62])：病斑小、易与背景混→检测头加 P2 小目标尺度、ShapeIoU 稳定小框。
  3. **蒸馏部署**([#67])：YOLO11x 教师蒸馏 YOLO11n 学生(CWD/MGD)→部署 Jetson Orin Nano / 树莓派 5(#67 实测可行)。
- **实验设计**：mAP50 / mAP50-95 + 边缘端 FPS/功耗；对照蒸馏前后精度-速度。
- **算力**：训练 4060 够；部署在边缘盒子。
- **里程碑**：7–8月 数据+训检测器；9月 蒸馏+边缘部署测试。
- **风险→对策**：检测框标注贵→半自动预标+锚定溃疡；小目标漏检→P2 头。
- **价值**：落地=果园巡检检测盒子；研究=轻量边缘检测。

### 研究档（论文向，都在"纯RGB跨品种×Lab→Field"下，钩子各异）

**R1 · 域泛化（零目标标注）**
- **定位**：研究★★★ / 落地★★ / 周期 4–5 月 / 4060 够。
- **要解决什么**：最省数据的极端——胡柚**一张都不用于训练**，纯靠公开橙橘训练就想在胡柚上 work，适合目标域完全拿不到/不想标的情况。研究点=纯 RGB 跨品种下的域泛化(全库空白)。
- **数据·采集·标注**：源=多个公开橙橘/柑橘集(当多源域，免标)；目标=胡柚**仅测试 ~150，不进训练、不做训练标签**；采集 ~1 半天；**标注 ~0.5 人天**(只标那 150 测试)。全档最省。
- **方法(分步)**：
  1. **建 DG benchmark**([#27])：多个公开集设为不同"源域"、胡柚设为"未见域"，仿 #27 的 Lab→Field 域泛化协议。
  2. **消域特有信息**([#27] style-sensitive 蒸馏)：风格敏感蒸馏让 encoder 忽略背景/风格/品种这些域特有信号，只留病征。
  3. **学域不变类结构**([#27] logit-原型匹配)：类原型对齐，让"溃疡"判别不依赖域；开源 DG-PLDR 起步。
  4. 直接在胡柚测试(全程没用胡柚训练数据)。
- **实验设计**：baseline=ERM 直迁；对照 DG 各法(风格增广/DANN-DG)；指标=未见域(胡柚)Acc/宏F1 + t-SNE 看域不变性。
- **算力**：ResNet18/50，8GB 够。
- **里程碑**：7–8月 复现#27+建多源 benchmark；9月 迁胡柚测试；10月 消融+写作。
- **风险→对策**：DG 上界通常低于 UDA(没用目标数据)→卖点定在"零标注也有可用精度"，不刷高。
- **价值**：研究=首个纯 RGB 跨品种柑橘域泛化(可发)；落地=零采集门槛兜底。

**R2 · 对抗 UDA（少量无标签目标域）**
- **定位**：研究★★★ / 落地★★ / 周期 4–5 月 / 4060 够。
- **要解决什么**：比 R1 多用一点——胡柚**采几百张但不标**(无标签)，用对抗域适应把双重域差补回。这是四交叉真问题最正面的打法，也是精读证据最扎实的一套(#26)。
- **数据·采集·标注**：源=公开橙橘(有标签)；目标=胡柚**无标签几百(免标)** + FBR 合成 + 测试集 ~150 标；采集 ~2 半天；**标注 ~1 人天**(只标测试)。
- **方法(分步)**：
  1. **M0 坐实掉点**([#35]法)：公开橙橘训 baseline 直测胡柚，量化"跨品种+Lab→Field"双重掉点——课题第一个论据。
  2. **FBR 背景重组**([#26])：SAM 抠公开橙橘叶→贴胡柚园背景→合成复杂背景源样本，先缩视觉域差。
  3. **CDAN+E 条件对抗**([#26])：FBR 增广(源) vs 胡柚无标签(目标)做条件对抗——特征提取器 vs 域判别器，用分类预测做条件、熵加权。**不用 CORAL/MMD**(#26 证真实田间失效)。
  4. **跨品种少样本微调**([#22]思路)：若能标少量胡柚(每类 20–30)，再微调补跨品种残差。
- **实验设计**：baseline 直迁；对照=FBR only / UDA only / FBR+UDA(把 #26 的 47→91 曲线复刻到柑橘)；消融各件；Grad-CAM 证聚焦病斑不被背景带偏。
- **算力**：ResNet18 + 域判别器 MLP，batch64，8GB 够；对抗 ~300 epoch。
- **里程碑**：7月 M0 掉点；8月 FBR+对抗；9月 少样本微调+消融+可视化。
- **风险→对策**：跨品种纯 RGB 或补不满→"揭示双重域差+部分缓解"即贡献；L1 落地兜底。
- **价值**：研究=把 #26 从同物种扩到跨品种柑橘、四交叉正面解(可发)；落地=无标签即可用。

**R3 · 自监督跨品种迁移**
- **定位**：研究★★★ / 落地★★★ / 周期 4 月 / 4060 够(预训练稍重)。
- **要解决什么**：把 L1 的"自监督预训练+微调"上升为**系统研究**——系统评估"用什么自监督、什么预训练源，对橙橘→胡柚跨品种迁移增益最大"。落地研究两占。
- **数据·采集·标注**：预训练=公开橙橘/柑橘(无标签，越多越好)；微调=胡柚每类几十~200；测试~150；采集 ~2 半天；**标注 ~2–4 人天**(分类)。
- **方法(分步)**：
  1. **自监督预训练**([#55 PlantCLR / #54 统一自监督])：对比学习(SimCLR)或掩膜重建(MIM/BYOL)在公开柑橘上预训练 ResNet/ViT，学跨品种通用病征。
  2. **胡柚少样本微调**：预训练权重上微调，测数据效率。
  3. **系统对照**：ImageNet vs 通用植物 vs 柑橘专用 三种预训练源 × 对比/掩膜两类自监督，看哪组合对跨品种迁移最优。
- **实验设计**：核心是**数据效率曲线**(胡柚标注 5/10/30/100 张 → 精度)，证"自监督让少样本跨品种更省标注"；对照不同预训练源/自监督法。
- **算力**：自监督预训练 batch 越大越好→梯度累积/降分辨率，4060 可跑(时间换显存)。
- **里程碑**：7–8月 各自监督预训练；9月 微调+数据效率实验+对照。
- **风险→对策**：自监督调参敏感→用成熟 SimCLR/BYOL 配方、别自创。
- **价值**：研究=跨品种迁移的自监督系统评估(可发)；落地=顺带产出好用的预训练权重给 L1。

**R4 · 少样本元学习**
- 定位：研究★★★/落地★★/周期 4 月。钩子：直击"每类几十张"，新病种快速上手。
- **数据·采集·标注**：基类=公开橙橘(免标)；新类=胡柚溃疡/炭疽各 **5–30**；采集 ~1–2 半天；**标注 ~1–2 人天**(极少量分类)。
- 方法：①[#56]监督对比 encoder→②元学习 N-way K-shot→③评 5/10/30-shot。实验：K-shot Acc 曲线。算力：省 GPU，轻松。

**R5 · 生成式桥接**
- 定位：研究★★★/落地★★/周期 5 月。钩子：扩散生成胡柚复杂背景病叶，从根上解自采少。
- **数据·采集·标注**：公开橙橘/胡柚少量做条件 + 无标签果园背景；采集 ~1–2 半天(主要采背景+少量病叶)；**标注 ~1–2 人天**。
- 方法：①[#49]SD-v1.4+DreamBooth 室内→室外翻译→②生成样本混训→③专家偏好筛真。实验：FID/IS+下游增益；对照 FBR vs 扩散。风险：4060 训扩散吃力→LoRA+推理为主。

**R6 · 跨域复杂背景检测**
- 定位：研究★★★/落地★★/周期 5–6 月。钩子：复杂背景**检测**+跨域，直接对接田间。
- **数据·采集·标注**：源=公开橙橘；目标=SciDB/#36/#7 + 自采**逐框标**；采集 ~3–4 半天；**标注 ~4–8 人天**(检测框，全档最贵)。
- 方法：①YOLO/Faster-RCNN→②[#42]MGA 多粒度跨域对齐→③FBR+跨品种微调。实验：跨域 mAP+消融三粒度。算力：偏紧→降分辨率/梯度累积。

**R7 · 开放集（未见病不误判）**
- 定位：研究★★★/落地★★/周期 5 月。钩子：田间遇训练没见过的病，认得出未知、不硬套。
- **数据·采集·标注**：已知类=健康/溃疡等；未知=留出若干病种模拟；采集 ~2 半天；**标注 ~2–3 人天**(分类+划未知)。
- 方法：①[#69]开放集自+跨域适应→②结合 R2 域差处理→③多品种测未知检出。实验：闭集 Acc+开集 AUROC。

### 组合档

**C1 · 渐进（推荐）**：先 **L1**(必交付) → 同底座叠 **R2/R3**(研究点) → 有余力接 R6。数据上极省起步：M0 只需公开源域+150 张胡柚测试(~1 半天采集+0.5 人天标注)拿掉点，再按实际采集/人力叠。
**C2 · 空地协同（可选·远期）**：需无人机，证据最弱(#37 已纠正为人体动作)。地面端=L1/L3，无人机端 YOLO 筛查+GPS 交接。

## §6 怎么挑（让数据工作量倒逼选型）
1. **先按你能承受的标注量筛**：一张不想标→**R1**(0.5 人天)；能采不想标→**R2**(无标签)；能标少量→**L1/R3/R4**；标注预算足且要检测→**L3/R6**。

3. **不确定→C1 渐进**：M0 极低成本(1 半天+0.5 人天)起步拿掉点，看采集与反馈再叠某条 R。
4. 想把某套细化成**逐周可执行方案**(网络/超参/周计划/预期指标/每周采集标注任务)，点名即可。
