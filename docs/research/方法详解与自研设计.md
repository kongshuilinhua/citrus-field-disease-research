## 引言 · 从复现实测得到的 4 条立足点（方法设计的依据）

1. **实验室干净背景分类已饱和**：EfficientNet-B0 / ResNet50 / MobileNetV3 在 Mendeley 5 类均 94.96~95.80%、第 3 epoch 收敛 → **不该再刷干净精度**。
2. **跨域掉点巨大且依架构**：干净模型搬到 CitrusUAT（orange）严格 5 类掉到 22.4~49%（轻量骨干最惨，ResNet50 反稳 82.5%）→ 真正矛盾是**"轻量部署 vs 抗域移"**。
3. **域适应能补回**：DANN 把 CitrusUAT 上 2 类准确率 30.1%→87.4%（+57.3pt）→ **方向正确**。
4. **缺素黄化被大量误判成黄龙病**：MobileNet 上 Fe/Mg/N/Zn 89~100% 被判成 HLB → **必须做开放集 / 鉴别**。
   另：手上已有 **SciDB 真田间复杂背景**数据（15 类含溃疡/炭疽/黄龙病症状），尚未用于跨域实验，是现成金矿。

# 第一部分 · 现有方法详解

## 一、域适应族（实验室→田间 + 跨品种）—— 主线

### #35 MSUN《From Laboratory to Field》★方法骨架（Plant Phenomics 2023，无代码）
- **问题拆解**：源域(实验室:单叶/干净/高清) vs 目标域(田间:多叶/复杂背景/模糊/遮挡)，归为三类不确定性：①大域间差；②域内大类内差（同病不同状态/部位）；③类间边界模糊（不同病相似表现）。
- **结构**：特征生成器 g(·) + Inception 适配模块 h(·)（多个不同 kernel 的子结构）+ 分类器 c(·)。
- **三大组件**：
  1. **多表示（Multirepresentation）**：Inception 式混合结构提取多个域不变表示，学整体结构+多尺度细节，缓解大域差（避免单表示只抓局部）。
  2. **子域对齐（LMMD，局部最大均值差异）**：按**类**对齐相关子域（同类源↔目标）的特征分布，保语义、解决类间相似；目标域无标签 → 自训练生成**伪标签**，用**软预测（概率）**缓解伪标签错误。
  3. **不确定性正则**：半监督式，把决策边界推向**低密度区**，抑制迁移不确定性。
- **非对抗**训练。结果 PlantDoc 56% / Plant-Pathology 72% / Corn 96.8% / Tomato 50.6%。
- **可借鉴**：我 DANN（全局对抗）→ 升级到 LMMD 子域（按类）对齐 + 多表示 + 不确定性正则。这是我域适应的主升级路线。

### #26 FBR-UDA《背景重组增强的 Lab→Field UDA》★有开源代码（Ecological Informatics 2026）
- **两步法**：① **FBR（Field-adaptive Background Recomposition）**：**SAM 抠叶** → 把实验室干净叶子重组/贴到**田间背景**上做增广（形态学 erosion/dilation/高斯模糊处理边缘）；② 在增广数据上做 UDA。
- **系统对比多种 UDA**：DANN / CORAL / DCORAL / DDC / MMD / NWD / DALN / **CDAN+E（条件对抗+熵）**，找田间最优。
- 数据 PVD→PPD + AI-Hub-L/R；作物 tomato/chili/grape/apple。代码 github `LABA-SNU/FBR-UDA`。
- **可借鉴**：我方案"FBR 数据侧桥接"的出处（有代码可直接起步）；其 UDA 对比是"选哪个域适应法"的直接参考。

### #42 MGA《Multi-Granularity Alignment》跨域**检测**（Plant Phenomics 2025）
- 兼容主流检测器的 DA 框架 = 多粒度对齐 + 全尺度门控融合；**三级判别器**（category / instance / pixel 三粒度识别域来源）从粒度依赖视角对齐；scale-aware 卷积聚合。
- mAP 47.9(PVi→CDi)/48.3/49.2；接 Faster R-CNN 44.7。
- **可借鉴**：将来做 SciDB 田间**检测**的跨域适应时的骨架（检测版 DA）。

### #43 ITTA《多域增强 + 隔离测试时自适应》（ESWA 2025）
- ①多域增强：强增强(GAN 生成保类别一致) + 弱增强(高斯噪声/亮度)；②**ITTA**：teacher-student + **Fisher 信息矩阵(FIM)** 分离"域敏感 / 域不变"参数，**测试时只更新域敏感参数**，防灾难性遗忘。
- **测试时自适应（TTA）**：部署后在线适应新域、不重训。
- **可借鉴**：部署到新果园/新季节、采集条件持续变时的**在线自适应**思路。

### #57 UDA-FT（RSE 2025，遥感农田分割）
- Mask R-CNN + target 导向 teacher + student(image/instance adaptation 对抗) + 一致性互学习 + **软伪标签** + CutMatch/LeakyMask 增强。
- 遥感农田实例分割，**非柑橘主线**；仅借鉴"软伪标签 + teacher-student + 一致性"。

## 二、自监督 / 迁移 / 小样本预训练族

### #55 PlantCLR《对比自监督预训练》★R3 直接参考（Sci Reports 2026，有代码）
- SimCLR 式（同图两增广视图拉近、异图推远）+ **ConvNeXt-Tiny 轻量 backbone** + 微调轻量分类头。
- **严格两阶段协议：train/val/test 完全分离防信息泄漏**；跨数据集迁移评测（PlantVillage 实验室 → Cassava 田间）评表示鲁棒性。
- PlantVillage 99.10% / Cassava 96.83%；t-SNE + Grad-CAM。
- **可借鉴**：自监督直接模板；轻量 ConvNeXt-Tiny 适合手机；**其严格防泄漏协议正是我 SimCLR 复现要修的依据**；"实验室→田间跨数据集迁移"评测设计 = 橙橘→胡柚。

### #54 统一自监督（Electronics 2025）
- ResNet101 + **三目标混合：BYOL + MIM(掩膜重建) + 对比学习**，混合损失(全局对齐+局部结构+实例区分)。
- PlantDoc 77.82%；微调 PlantVillage 99.85%。
- **可借鉴**：单一 SimCLR 增益不够时，上"BYOL+MIM+对比"多 pretext 混合。

### #56 监督对比 + 元学习少样本（Front Plant Sci 2024）
- 两阶段：①**监督对比学习**训编码器(用标签，比无监督对比好、小 batch 省 GPU)；②**元学习 + 最近质心分类器**(距离度量)做少样本。
- 自然场景土豆病 30 张 → 79.51%。
- **可借鉴**：自采稀缺类的**少样本**方案；监督对比省 GPU（适配 4060）。

## 三、数据侧 / 生成族（桥接域差、扩样本）

### #53 Leaf-Only-SAM《零样本抠叶》★有代码，已复现
- SAM 自动分割 → 后处理筛叶：绿色筛(HSV hue 35–75) → 去整株(iou<0.9) → 形状筛(面积/最小外接圆>0.1) → 去重叠大块。**免训练零样本**。
- **可借鉴**：抠叶前置（把田间多叶抠成单叶，与公开单叶对齐；或抠叶去背景）；即插即用。

### #49 农业扩散生成（arXiv 2025）
- ①文本条件合成(微调 SD-v1.4)；②**室内→室外翻译**(DreamBooth 文本反演+图像引导扩散，提升 YOLOv8)；③专家偏好对齐(reward model)。
- **可借鉴**：扩散把"干净/室内"叶翻译到"田间/室外"桥接域差；DreamBooth 室内→室外正对 lab→field。算力偏重，4060 做推理/轻量微调可行。

## 四、开放集 / 未知类族

### #69 OSDA《开放集自/跨域适应》★治"缺素↔HLB 误判"（Front Plant Sci 2021）
- **开放集域适应(OSDA)**：把诊断当开放集学习——目标域运行时精确估计"未知(unknown)"，同时保已知类性能；约束样本要么归目标类之一、**要么标 unknown**。
- **可借鉴**：直接治 M0 暴露的"缺素被误判成 HLB"——把没见过的类判为 **unknown** 而非硬塞已知类。
- #68 知识集成异常检测 [摘要级]：异常检测+知识集成识别未见病，与 #69 互补。

## 五、网络改进 / 多模态 / 轻量部署族（简述）

- **#36 三通道聚合注意力**（有原版代码+SciDB 数据）：C2f-Attention-IRMB（倒残差移动块+注意力，增强微小病斑）+ Powerneck（SimFusion_4in 多尺度对齐 → IFM 全局融合 → power_channel 动态加权），复杂田间 mAP50 97%。→ 田间**检测**的强骨干参考。
- **#28 YOLOV8-CMS**：CSPPC/MultiDimen/SpatialConv，柑橘叶病分类分级（无代码，我做过重建）。
- **#18 图文多模态+知识** [摘要级]：图像分支 + 文本分支(病害症状术语表)，CLIP/TextCNN 融合，文字知识补少样本+复杂背景，且**文字在橙橘↔胡柚间通用可缓解跨品种**。
- **#47 AgriCLIP / #48 VLM**：CLIP 农业域适配、视觉-语言融合（可选研究增量）。
- **蒸馏族 #65 FPDD-Net / #66 KD / #67 CWD-MGD**：知识蒸馏做轻量高效，上手机的关键。

# 第二部分 · 我自己打算做的方法（详细设计）

## 0. 总体路线（渐进式，一条底座往上长）

```
公开橙橘/柑橘  ──自监督/迁移预训练──▶ 通用病征表示
                                      │
常山胡柚自采(少量) ──少样本微调──▶ 胡柚分类器(落地底座)
                                      │
                     ┌────────────────┼────────────────┐
              域适应对齐          开放集拒识          轻量化蒸馏
         (跨品种×Lab→Field)     (缺素/未见→unknown)   (量化上手机)
```

**一句话**：公开预训练 → 胡柚少样本微调 → 域适应补掉点 → 开放集治缺素混淆 → 蒸馏量化上手机；同底座生长，落地与论文兼顾。

## 1. 设计原则（据实测）
- 不刷干净精度（已饱和）；重心放"**轻量模型的域鲁棒性**"（实测轻量最不抗域移）。
- 公开数据"打底"、自采胡柚"主导"，分主次分阶段（不等量混训）。
- 黄龙病不现场自标（需 PCR），靠公开确诊集；缺素/未见类走**开放集拒识**。

## 2. 模块化详细设计

### M0 · 真田间掉点量化（立即，不依赖自采）
- **动机**：现有 M0 只在 CitrusUAT（干净 orange），还没覆盖"复杂田间背景"这一重。
- **做法**：用已训干净模型，零再训直接在 **SciDB（真田间，15 类含溃疡/炭疽/黄龙病）** 上测；按类别重叠（健康/溃疡/黄龙病症状）报掉点；把 SciDB 检测框裁成分类图或直接做检测评测。
- **产出**：一张"干净→真田间"掉点表 + 误判去向（尤其缺素/黄龙病混淆），作为课题第一硬论据。
- **借鉴**：#35 的问题拆解框架；评测口径参考 #55 严格分离。

### M1 · 领域内自监督预训练（省标注的根）
- **动机**：胡柚标注贵、量少；实测 ImageNet 微调对域移弱。
- **做法**：在**大量公开柑橘 + 自采未确诊胡柚**（都无标签）上做对比自监督预训练（**SimCLR 式**，backbone 用**轻量 ConvNeXt-Tiny / EfficientNet-B0** 对齐手机）。**严格 train/val/test 分离防泄漏**（修当前复现的泄漏 bug）。单 SimCLR 增益不足则上 **BYOL+MIM 多 pretext 混合**（#54）。
- **借鉴**：#55 PlantCLR（模板+轻量骨干+防泄漏协议）、#54（多目标）、#56（监督对比省 GPU）。
- **评测**：数据效率曲线（胡柚标注量→精度）+ 线性探针；对照 ImageNet vs 柑橘自监督。
- **算力**：4060 Ti 16G 够（对比学习 batch 可 128、ResNet18/ConvNeXt-Tiny）。

### M2 · 跨品种 × Lab→Field 域适应（核心创新点）
- **动机**：实测 DANN +57pt 有效，但①只在干净 orange；②DANN 是全局对齐，粗。
- **做法（分层升级）**：
  1. **基线**：DANN（已验证）。
  2. **升级到子域对齐**：按 #35 MSUN 用 **LMMD** 做**按类**子域对齐 + **多表示** + **不确定性正则**（目标域伪标签用软预测）——比 DANN 细、非对抗更稳。
  3. **数据侧桥接**：#26 **FBR**（SAM 抠叶 + 贴田间背景合成），有开源代码；对比 CDAN+E / CORAL / MMD 选田间最优。
  4. **（可选）在线自适应**：#43 ITTA（FIM 只更新域敏感参数），应对新果园/季节漂移。
- **借鉴**：#35（主）、#26（数据桥+代码）、#43（TTA）。
- **评测**：源域(公开橙橘)训 → 目标域(SciDB 田间 / 胡柚自采)测；对照"直迁 vs DANN vs LMMD vs +FBR"；消融；t-SNE 可视化对齐。
- **创新落点**：**"跨品种(橙橘→胡柚) × 实验室→田间 双重域差的量化与缓解"，且聚焦轻量模型的域鲁棒性**（据实测矛盾）。

### M3 · 开放集拒识（治缺素↔黄龙病混淆）
- **动机**：M0 实测缺素被高比例误判成 HLB；自采会遇大量训练集没有的病/虫/缺素。
- **做法**：在分类/检测头上加**开放集识别**（#69 OSDA 思路）——样本要么归已知类、**要么判 unknown**；结合 #68 异常检测/知识。早期黄龙病与缺素难分者优先拒识、提示人工/PCR 复核。
- **借鉴**：#69（主）、#68。
- **评测**：已知类准确率 + 未知类(缺素/新病)召回为 unknown 的比例；对照闭集 vs 开放集。

### M4 · 数据侧桥接与扩增（贯穿 M1–M3）
- **抠叶**：#53 Leaf-Only-SAM（零样本，已复现）把田间多叶抠成单叶，与公开单叶对齐；或抠叶去背景统一形态。
- **背景合成**：#26 FBR 把干净单叶贴田间背景；**（可选）** #49 扩散 DreamBooth 室内→室外翻译（算力重，仅推理/轻量微调）。
- **少样本/不均衡**：#56 少样本 + 重采样/Focal Loss（melanose 这类稀缺类）。

### M5 · 轻量化上手机（落地）
- **做法**：知识蒸馏（#65 FPDD / #67 CWD-MGD，大模型教师→轻量学生）+ INT8 量化，导出 ONNX/TFLite；App 引导"对准单叶拍"或内置轻量抠叶。
- **目标**：<10MB、实时；对照精度-延迟-体积。
- **借鉴**：#65/#66/#67、#28 移动端思路。

### （可选增量）M6 · 图文多模态知识辅助
- #18 图像分支 + 病害症状文字术语表（CLIP/TextCNN 融合），文字知识补少样本+复杂背景，且**术语在橙橘↔胡柚通用、辅助缓解跨品种**。用户感兴趣，作为可选研究点。

## 3. 数据方案
- **预训练（公开，无标签）**：Mendeley + 4 类橙叶 + PlantVillage(柑橘) + 自采未确诊胡柚。
- **微调/目标域（自采，主导）**：常山胡柚/香柚，单叶+自然背景，整图分类标签起步；锚定"健康+溃疡"，逐步扩炭疽/缺素。
- **确诊**：黄龙病靠公开 PCR 确诊集（CitrusUAT/SciDB），不现场自标。
- **★自建"胡柚田间基准"**：规范采集 + 确诊标注，作为最抗风险的贡献（无胡柚公开集）。

## 4. 评测方案
- 分类：Accuracy / 宏 F1 / 各类 F1；跨域协议(源训目标测)；开放集：unknown 召回。
- 落地：模型大小 / 手机端延迟-FPS。
- 消融 + t-SNE 特征对齐可视化。

## 5. 创新点 / 论文抓手（三选或组合）
1. **首个"常山胡柚田间数据集/基准"**——最抗风险，方法涨不涨点都成立。
2. **跨品种 × 实验室→田间 双重域差的量化与缓解**，聚焦轻量模型域鲁棒性（DANN→LMMD+FBR，已有 +57pt 初步证据）。
3. **缺素黄化 vs 黄龙病 鉴别 / 开放集识别**（M0 已实测这是真难点）。

## 6. 算力可行性（单张 RTX 4060 Ti 16GB）
- 分类/自监督/域适应/蒸馏：全部够（轻量骨干、batch 可观）。
- 检测(SciDB 7192 图)/扩散微调：偏重，降分辨率/减 batch/仅推理可行。

## 7. 风险与兜底
- 跨品种差距或没想象大（实测 ResNet50 在 orange 还有 82.5%）→ 重心转"轻量域鲁棒性 + 真田间 + 开放集"，且**自建基准**作保底贡献。
- 自采不顺/确诊难 → 先用公开(SciDB/CitrusUAT)把管线与掉点做扎实，自采即插即用；黄龙病全靠公开确诊集。
- 长训练/环境不稳 → 已知（可续跑、workers/OMP/中文路径坑已解）。
