## #35 MSUN — From Laboratory to Field: UDA for Plant Disease Recognition in the Wild
Plant Phenomics 2023 · 南京林业大学 · CC BY 4.0 · **纯 RGB**

**一句话定位**：Lab→Field 无监督域适应（UDA）的**方法奠基作**，但**它不是柑橘论文**——source=PlantVillage(实验室,38类通用作物)，target=PlantDoc/苹果/玉米/番茄。之前把它当"柑橘核心"定位有偏差；它的真实价值是**范式 + 田间掉点的通用铁证**，不是柑橘特异性。

**硬数据（田间掉点铁证）**——无 DA 直接迁移 vs 最强 DA(MSUN)：

| 任务(target 田间) | 无DA baseline | MSUN | 说明 |
|---|---|---|---|
| PlantDoc(27类·多物种) | **30.78%** | 56.06% | 多物种最难 |
| 番茄(5类) | **21.46%** | 50.58% | 类间相似度高，惨 |
| 苹果 Plant-Pathology(3类) | **39.27%** | 72.31% | |
| 玉米(4类) | 75.96% | 96.78% | 唯一高：玉米病类间差异大 |

→ **铁证**：实验室训练直接测田间，多数掉到 **20–40%**；即便最先进 UDA 也只能补到 **50–72%**（除类间差异大的玉米）。"实验室 99%" 到田间是幻觉。

**方法机制（三件套）**：
1. **多表示模块**：Inception 式 hybrid，g(·) 降像素 + h(·) 用 4 个 substructure(1×1/3×3/5×5 核+池化组合)提多个表示。动机：田间背景有果/枝条等无关信息，单表示会被带偏，多表示兼顾病斑细节与整叶-背景关系。
2. **子域适应(LMMD)**：不做全局 MMD，按类切 C 个子域，用 LMMD 对齐**同类子域**；目标域无标签→self-training 伪标签(soft 概率加权)。动机：跨物种"类内差异大+类间相似高"，全局对齐会语义错位。
3. **辅助不确定性正则(熵最小化)**：伪标签不可靠→熵最小化把决策边界推向低密度区，抑制伪标签噪声。
- 消融(C-PD)：30.78(base)→+多表示→+LMMD→+熵 = 56.06，三件套均有效。

**实现（对 4060 的警示）**：backbone=ResNet50(ImageNet 预训练)；硬件=**GTX 3080Ti 24GB**；输入 224；SGD 200 epoch；λ 渐进 0→1(最优~0.7–0.8)，γ~0.1。→ 我们 4060/8GB 复现：多表示+双域 batch+LMMD 显存吃紧，需压 batch 或换轻 backbone。

**对本课题价值**：① 田间掉点数字 = 课题"问题成立"最硬论据；② 证明**纯 RGB 做 Lab→Field 可行**(但天花板 50–72%)；③ LMMD 子域对齐是可借的方法骨架。

**不适用 / 关键局限（切入点所在）**：
1. **粒度不对**：做的是 cross-species(跨物种/跨采集环境)，**没碰 cross-cultivar(橙橘→胡柚 同属跨品种)**这个中间粒度——我们的真问题它没解决。
2. **数据量假设与我们冲突（最要命）**：MSUN 是 UDA，前提是**目标域有大量无标签数据**(PlantDoc 5601 张、番茄 2908 张)。我们自采胡柚只有几十~几百张 → **MSUN 的核心前提在我们场景不成立，不能照搬**。
3. **无落地考量**：纯刷精度，无部署/轻量化/手机端。
4. 论文**没有 Limitations 章节**（Conclusion 只讲贡献）；上述局限是从其方法假设与实验设置推出的。

**→ 由此浮现的切入点**：真正的空白 = "**小样本目标域 + 跨品种(cross-cultivar)**"下的 Lab→Field——MSUN 假设的大量无标签目标数据我们没有，它做的跨物种也不是我们的跨品种。两点叠加，正是"非做不可、别人没覆盖"的缝隙。**待 #22/#26 验证后收敛。**

## #22 跨数据集迁移·柑橘 HLB — Implementing transfer learning for citrus HLB detection across different datasets
Computers and Electronics in Agriculture 2025 · 福建农林大学 · Elsevier(付费墙) · **多光谱+多色荧光成像(非 RGB)**

**一句话定位**：柑橘 HLB **检测(Mask-RCNN 系)**，一个品种预训练→迁移到另一品种，是最接近"橙→胡柚"的 **跨品种(cross-cultivar)** 范式。但——**它靠自研多光谱荧光设备，不是手机 RGB；且在暗室受控、背景简单，根本没碰复杂田间。**

**数据/设置(极贴我们的品种维度)**：4 个柑橘品种，每类 3 种(健康/HLB/缺素)：
- 脐橙 Navel(data-1,808 叶)→预训练源；**沃柑 Orah(data-2,709)→迁移目标**
- 血橙(645)/椪柑 Ponkan(438)/脐橙 2022(760)→跨品种×跨时空验证
- 采集：叶片摘下→暗适应 30min→**暗室(darkroom)** 放工作台成像；PCR 做金标准标签

**成像 = 多光谱(关键，回答 task2)**：自研手持设备(CCD+滤光轮+UV 激发)。多色荧光 440/520/690/740nm(4) + 多光谱反射 460/520/680/740/840/940nm(6) = **10 通道** → PCA 降维取前 3 主成分 → 合成 3 通道伪彩色图 → 喂检测网。**"图像"根本不是 RGB 照片，是光谱数据，手机拿不到。** 论文明确主张"多光谱能揭示 RGB 捕捉不到的信息"。

**硬数据(跨品种迁移)**：Mask-RCNNV3(MobileNetV3-large backbone) mAP@0.5=93.37%；跨品种迁移后 沃柑 93.14% / 血橙 91.82% / 椪柑 92.36%。**最佳每类迁移样本 = 20 张/类**，迁移前 9 层涨点。参数/GFLOPs 降 82.95%/96.57%，FPS×4，可边缘部署。
- 硬件 = **NVIDIA 2080 super(8GB!)**，batch 4，100 epoch，SGD → **8GB 可复现，比 MSUN 的 24GB 友好。**

**对本课题价值**：① 跨品种差距其实**没那么大**——同属柑橘不同品种，每类 20 张标注微调就 90%+，暗示橙橘→胡柚可能不需要重型域适应，少量自采微调就够(利好落地)；② 8GB 可跑，轻量化+边缘部署被验证；③ "一品种预训练→多品种验证"的实验设计可直接借。

**不适用/关键局限(切入点所在)**：
1. **依赖多光谱荧光设备**——手机纯 RGB 拿不到，它的 90%+ 是**设备红利**，不能直接推给手机 RGB。
2. **暗室+背景简单，完全没碰复杂田间**：论文自陈"背景不复杂、相对简单"。它解决的是"跨品种+跨时空的**光谱域差**"，不是"干净→复杂背景的**视觉域差**"。
3. 病种绑定 HLB(需 PCR)，不是溃疡/炭疽等夏季可视病。

**→ 关键交叉发现（#35 × #22，方案的支点）**：
| | 跨品种 | 复杂田间背景 | 纯RGB/手机 | 小样本目标域 |
|---|---|---|---|---|
| #35 MSUN | ✗(跨物种) | ✓ | ✓ | ✗(需大量无标签) |
| #22 迁移 | ✓ | ✗(暗室) | ✗(多光谱) | ✓(20/类) |
| **你的场景** | ✓ 橙橘→胡柚 | ✓ 常山果园 | ✓ 仅手机 | ✓ 自采少 |

**没有一篇同时啃下「纯 RGB 手机 + 跨品种(橙橘→胡柚) + 真实复杂田间 + 小样本」四交叉**——而这正是你的真实条件逼出来的。旧方案空喊"跨品种 DA 文献少"，现在能精确指出空白在哪。**待 #26 看"背景重组"能否补上视觉域差这条。**

## #26 FBR-UDA — Bridging the Lab-to-Field gap ... enhanced by background recomposition
Ecological Informatics 2026 · 首尔大学 · **开源(GitHub `LABA-SNU/FBR-UDA` + Zenodo)** · CC BY · 纯 RGB · ResNet-18

**一句话定位**：旧方案"M2 SAM 抠叶+背景替换+DANN/CORAL"的**完整端到端出处，且开源**。两步法补"干净→复杂背景"的**视觉域差**。但仍是**同物种跨环境(苹果→苹果)，无跨品种**。

**方法(两步)**：
1. **FBR(背景重组)**：SAM 中心点 prompt 抠叶(实验室图叶片居中)→形态学精修 mask(膨胀 kd15/腐蚀 ke10/高斯 kg5，迭代2)→贴到真实田间背景(无标签田间图随机旋转裁剪)→合成"类田间"增广图。
2. **UDA**：在 FBR 增广(源)与真实田间(目标)间再对齐。对比 DDC/DCORAL(分布式)、DANN/CDAN+E(对抗)、DALN(混合)。

**硬数据(genuine: PVD→PPD 苹果, Lab→Field)**：
| 配置 | 苹果田间 Acc |
|---|---|
| Baseline(无FBR无UDA) | 47.1% |
| 仅 FBR | 57.0% (+9.9) |
| 仅 UDA(CDAN+E) | 88.4% (+41.3) |
| **FBR+UDA(CDAN+E)** | **91.1%** |
| Real-to-Real 上界 | 97.7% |

**两个反常识发现(直接改方法选型)**：
1. **对抗式 UDA ≫ 分布式 UDA**：真实设置里 DDC/DCORAL/MMD 几乎无效(57–61%)，只有对抗式 DANN/CDAN+E 有效(91.1%)。Grad-CAM 证：对抗式聚焦病斑忽略背景，分布式仍被背景带偏。→ **旧方案 M1 把"DANN/CORAL/MMD"并列是错的**，CORAL/MMD 在真实田间失效，应主推 CDAN+E 式**条件对抗**对齐。
2. **UDA 贡献 ≫ 背景重组**：仅 FBR 只 +9.9，仅 UDA +41.3。→ **旧方案把"M2 背景重组"当重头戏是主次颠倒**；背景重组是辅助，对抗 UDA 才是主力。

**实现(4060 友好)**：ResNet-18(ImageNet 预训练)+FC 分类头+域判别器 MLP；输入 224，**batch 64**，AdamW lr0.001，CosineAnnealing；对抗式 300 epoch。→ **8GB 充足。**

**对本课题价值**：① FBR 工具链(SAM 抠叶+贴背景，开源)可直接复用——把公开橙橘干净图抠叶贴常山果园背景，合成复杂背景橙橘，**缓解自采少**；② CDAN+E 是真实田间该用的 UDA 基线；③ 47→91 的回补曲线可作我们对照实验模板。

**不适用/局限**：① **无跨品种**(苹果→苹果同物种)；② 仍需一批**无标签田间目标图**(PPD 900 张)；③ FBR 合成有边界伪影，单独用离上界差 40%(靠 UDA 补)；④ 承认"拿不到田间标注测试集"(实用案例 P-Chili 只能报验证集)——农业 AI 通病。

## 三篇核心精读 · 收敛（重做方案的地基）

**缝隙锁定**：
| | 跨品种(橙→胡柚) | 复杂田间 | 纯RGB/手机 | 小样本目标域 | 开源/8GB |
|---|:---:|:---:|:---:|:---:|:---:|
| #35 MSUN | ✗跨物种 | ✓ | ✓ | ✗需大量无标签 | — |
| #22 迁移 | ✓ | ✗暗室 | ✗多光谱 | ✓20/类 | ✗ |
| #26 FBR-UDA | ✗同物种 | ✓ | ✓ | 半(需无标签田间) | ✓ |
| **你的场景** | **✓** | **✓** | **✓** | **✓** | 需要 |

**四交叉「纯 RGB + 跨品种 + 复杂田间 + 小样本」无人覆盖，且正是你的真实约束。**

**方法地基(有据选型，非堆模块)**：
- 视觉域差(干净→复杂背景)：复用 #26 FBR + **CDAN+E 条件对抗**UDA(开源、8GB、苹果 47→91 验证)。
- 跨品种(橙橘→胡柚)：#22 证 20 张/类微调即 90%+，用**少样本微调**，不上重型 DA。
- 别踩的坑：不无脑上 MSUN(它要大量无标签目标数据，我们没有)；不并列用 CORAL/MMD(真实田间失效)。
- baseline/掉点参照：#35 提供 Lab→Field 掉点铁证(20–56%)与 LMMD 子域对齐思路。

**旧方案被精读证伪的三处"缝合"**：
1. M1"DANN/CORAL/MMD"并列 → CORAL/MMD 真实田间失效(#26)，选型错。
2. M2"背景重组"当重头戏 → 主次颠倒，对抗 UDA 才是主力(#26 消融)。
3. 整套 M2 是复述 #26 已开源的端到端工作，未站在其上做增量。
