## 全库统计与结论（69 篇过完）

**① 跨品种(cross-cultivar) 维度**：全库仅 **3 篇**碰过——#22(多光谱)、#24(叶绿素荧光)、#45(高光谱)，**无一例外依赖光谱/荧光设备**。→ **纯 RGB 跨品种 = 0 篇。**

**② 四交叉「纯 RGB + 跨品种 + 复杂田间 + 小样本」**：全库**无一篇**覆盖。空白**经全库验证成立**（非 3 篇臆断）。

**③ 意外收获——一批"专治自采少"的方法(比重型 UDA 更对路)**：
- **#55 PlantCLR**：自监督预训练+目标域微调，正是"橙橘→胡柚"范式，开源。
- **#56 少样本**：监督对比+元学习，**30 张/类即 80%**，省 GPU，直击自采少。
- **#27 域泛化**：不需目标域数据，开源 DG-PLDR。
- **#54 统一自监督**：Lab+Field 同训。

**④ 可复用的其它角色**：
- 视觉域差(干净→复杂背景)：#26 FBR(开源)、#42 MGA(检测 DA)、#43 ITTA、#69 开放集 DA。
- 田间柑橘检测 SOTA(RGB，可作 baseline/数据)：#7 DCH-YOLO11(含溃疡,9219图)、#36 三通道(12病,mAP97)、#17 YOLO-Citrus、#9 YOLO-EAF。
- 抠叶/分割：#53 Leaf-Only-SAM、#52 EMSAM；严重度：#58/#28/#29。
- 轻量化/蒸馏(手机端 M3)：#65、#67(Jetson/树莓派实测)、#62、#28(13.4MB)。
- 数据集：#36 柑橘12病、福建 SciDB(本地)、#34 大豆配对、#50 橙果。
