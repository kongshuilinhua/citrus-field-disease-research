# 柑橘病虫害现有图像数据提供清单

## 一、图片范围

请提供目前已有的全部相关图片，不预先限定病虫害种类、图片数量、拍摄距离、背景或标注情况。

以下图片都可以提供：

- 胡柚、香柚图片；
- 其他橙、橘、柚、柠檬等柑橘类图片；
- 病害、虫害、健康、疑似异常和无法判断的图片；
- 叶片、果实、枝条、整株、虫体及受害痕迹图片；
- 近景、稍远场景、复杂果园背景和纯色背景图片；
- 有标注、无标注、类别不确定或质量一般的图片；
- 同一对象的多张照片和连续拍摄照片。

不需要提前筛选或删除。后续会统一检查质量、重复图片、类别和使用方式。

## 二、已有信息一并提供

以下资料如果已经存在，请与图片一起提供；没有则不需要临时补做。

| 内容 | 说明 |
|---|---|
| 原有类别或文件夹名称 | 保留当前名称即可，不要求重新分类 |
| 品种 | 胡柚、香柚或其他柑橘；不清楚可留空 |
| 拍摄部位 | 叶片、果实、枝条、整株、虫体等 |
| 拍摄日期 | 有则提供 |
| 果园或地块 | 可以使用匿名编号 |
| 拍摄设备或人员 | 有则提供，可以使用匿名编号 |
| 原有判断或专家意见 | 包括疑似、待确认等记录 |
| 已有标注 | 分类表、检测框、掩膜、文字说明等均可 |
| 检测或确诊依据 | 有则提供；没有不影响图片交付 |

没有标签、没有拍摄信息或无法确认具体病名的图片，也请保留并提供。

## 三、提供方式

1. 优先提供原始图片；如果同时有裁剪图、压缩图或处理后的图片，也可以一起提供。
2. 保留原有目录和文件名，不需要重新命名、分类或划分训练集与测试集。
3. 已有Excel、CSV、Word或其他说明文件一并提供。
4. 数据量较大时可以按原文件夹压缩，或通过网盘、移动硬盘等方式提供。
5. 如方便，可另外提供一份简单清单，说明大致数量、品种和已有类别；没有清单也可以先交付图片。

## 四、特别说明

- 当前阶段以完整接收现有数据为主，不设置固定类别和每类数量要求。
- 原有标签不会直接视为最终真值，后续会统一复核。
- 黄化或疑似黄龙病图片也可以提供；如果没有可靠确诊依据，后续只按疑似症状使用，不作为黄龙病确诊样本。
- 图片质量、类别数量或信息完整度不足，不作为拒收理由。
