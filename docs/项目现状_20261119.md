# 项目现状（2026-11-19）

> 本文是仓库内的最新状态说明，取代 `PROJECT_STATE.md` 2026-09-05 版本与 `USER_REQUIREMENTS.md` 中"当前阶段性方向"的旧表述。
> 数字口径与方法边界以文中引用的报告和本地证据文件为准。完整数据、原始图片、权重和训练输出不入库，仓库只保存结论、清单和入口。

## 一、一句话现状

实际研究主线已经是**复杂田间目标检测 + 可靠性（拒识与候选复核）**，主要瓶颈定位在**分类而非定位**。SciDB 上已有可复现基线与三套测试条件，检测矩阵与"逐目标建模"的误差机制结论较稳定，可靠性机制成立；但 2026-10-27 起的方法改进尝试**尚无一项在公平协议下稳定超过强基线**，胡柚迁移仍缺专家真值。

> 口径提醒：`USER_REQUIREMENTS.md` 仍写着"不预设检测一定是主线"。这与 2026-09-20 之后的实际执行不一致。本文按实际执行描述现状，是否正式改写用户口径，待用户确认。

## 二、任务与评测协议

- 目标对象：常山胡柚与香柚，纯 RGB 手机拍摄，复杂果园背景；以病害和虫害为主，缺素等非生物胁迫不作为主要识别类别，但可作为未知/OOD 干扰测试。
- 主任务：检测（器官级框 + 类别）。分类降为辅助任务与部署形态。
- 数据划分（依据 Qiu et al. 2022，DOI 10.3389/fpls.2022.1002606）：
  - 条件 A：手机，田间或室内混合背景，本地整理为 train 7,192 / val 898 / test 602；
  - 条件 B：相机与 iPhone，田间自然背景，602 张（每类 43）；
  - 条件 C：B 中同对象取下后置白背景板，602 张（每类 43）。
  - 本地 testA/testB/testC 对应原文 T3/T5/T8 属**根据数量与类别构成推断**，数据包未直接给出 T 编号，引用时必须注明。
- **testB 与 testC 是同一批叶片/果实**，不能当独立植株合并统计；其差异含背景、构图、取样方式与拍摄人员多因素，不能只归因于背景。两套都是历史探索集，不是独立盲测。
- 类别映射以 `reports/2026-09-21/类别说明与评测协议依据.md` 为准，本地编号 12/13/14 与原文 S 编号错位，跨表引用必须经 `label_object.json`。
- 主指标：AP50–95 与 AP50 同时报告；固定框下的分类正确率单独报告，两者不混用。
- 硬性要求：至少 3 个随机种子并逐种子报告；同进程严格 FP32 共同复算；配置、权重、日志与逐图结果留档；失败实验必须留档。
- 网络公开图片只能作外部压力测试，不作训练数据，也不据此宣称可用性（见 `reports/2026-09-21/类别说明与评测协议依据.md`）。

## 三、已稳定的结果

### 3.1 SciDB 三条件基线（2026-09-20 补测，YOLOv8n）

| 测试集 | 图/框 | mAP50 | mAP50–95 | 固定 0.25 阈值单主目标正确检出率 |
|---|---:|---:|---:|---:|
| testA（混合背景对照） | 602/602 | 92.36% | 85.27% | 90.53% |
| testB（田间自然背景） | 602/602 | 85.72% | 77.64% | 78.57% |
| testC（B 中同对象转白底） | 602/602 | 84.99% | 80.14% | 75.42% |

- testA 复算与历史记录逐位一致（mAP50 92.3633025%），权重与评估流程一致后才使用 B/C 结果。
- **主要瓶颈是分类而非定位**：三组定位覆盖率均 ≥98.3%，而 testB/testC 的"定位正确但类别错误"分别是 testA 的 2.7 倍和 3.3 倍。
- 误判集中在视觉相近的类别对（黄化类互判、炭疽↔脂斑、缺素类互判），错误样本平均置信度 0.72–0.75，仅略低于正确样本，单靠提高阈值无法解决。
- 190 张胡柚外测无真值，只能作域偏移参考：A 拍摄者 96 张中 8 张无输出，B 拍摄者 94 张中 9 张无输出；煤污在两人间差异大（29 vs 9），需专家复核。

### 3.2 七架构检测矩阵（2026-11 受控比较）

| 方案 | 源 val | testB | testC | 种子 | 推理 |
|---|---:|---:|---:|---:|---:|
| YOLOv8n@640（基线） | 89.78 | 71.25 | 72.77 | 3 | 10 ms |
| YOLOv8n@960 | 88.28 | 71.09 | 77.99 | 2 | 21 ms |
| Faster R-CNN v2 | 89.06 | 77.56 | 82.95 | 3 | 52.7 ms |
| 两阶段（YOLO+DINOv2） | — | 77.40 | **84.04** | 3 | 34.4 ms |
| Mask R-CNN | 87.98 | **79.14** | 82.61 | 2 | 约 62 ms |
| RetinaNet | 88.41 | 79.10 | 80.37 | 3 | 23.5 ms |
| RetinaNet + 裁图重分类 | — | **79.73** | 82.94 | 3 | 约 34 ms |
| RT-DETR-l | **90.00** | 74.33 | 76.39 | 2 | 19–24 ms |

- testB 最优为 RetinaNet + 裁图重分类（79.73），testC 最优为两阶段（84.04）。
- **机制发现**：能否修好 S12 藻斑这类系统性缺陷，取决于**有没有对每个目标单独建模**（RoI 裁剪或 object query），不是骨干，也不是 RoI 裁剪这个具体实现。
- 源 val 与 B/C 反向：RT-DETR 源 val 最高（90.00）但 testB 提升最小（+3.08）；Mask R-CNN 源 val 最低（87.98）但 testB 提升最大（+7.89）。
- 救回 S12 之后，Mask 与 RT-DETR 的最低类变成 S8 缺镁。
- **口径提醒**：本表与 3.1 的 09-20 数字来自不同训练批次与选择协议，未做统一复算，不可互相替代或拼接比较。

### 3.3 可靠性机制（七模型口径）

| 指标 | testB | testC | 判据 | 状态 |
|---|---:|---:|---|---|
| 三信号融合 AUC（两阶段） | **0.887** | **0.895** | ≥0.85 | 通过 |
| 七架构 AUC 区间 | **0.832–0.933** | 同上 | ≥0.85 | 通过 |
| 拒识 15% 净增益（3 种子均值，conf ≥ 0.4） | **+7.92** | **+7.50** | ≥+3 | 通过 |
| 同上（全框口径） | +7.07 | +5.08 | ≥+3 | 通过 |
| 七模型 × 两条件共 14 个净增益 | 全部为正 | 同上 | — | 通过 |

- 三个信号：温度标定分类头（T=86.12）、七模型分歧度、检测器置信度；两两相关 0.196 / 0.283 / 0.493，非冗余。
- **关键限定**：不能断言"哪个架构净增益最高"——种子标准差（1.1–1.24）与模型间差（1.69）同量级。
- 候选列表：最不可靠 20% 的 top-3 覆盖 95.7%（随机为 21%），错误率从 31.6% 降到 4.3%。

### 3.4 应用性观察

- 模型对色相高度敏感：±5° 无损，±10° 掉约 3 点，±20° 掉 8.6–9.9 点；饱和度几乎无影响，明度 ±20% 影响在 −2.0 到 +0.7 之间。
- testC 上两个高 AP 方案错误结构几乎相反（Faster 假阳性 16.3%/漏诊 2.1%，两阶段 2.3%/5.6%），但 testB 上差距小得多，该现象不能外推。

## 四、方法改进进展（2026-10-27 长期目标）

长期目标：先在公开数据上查明差距，提出并实现针对实际错误的改进，在公平协议下取得相对强基线的稳定收益，再验证胡柚迁移。

强基线口径：原生 YOLOv8n 受控训练，同进程严格 FP32 复算，源 val **AP50–95 = 90.6759%**、AP50 = 96.2365%。

| 尝试 | 结果（AP50–95） | 判定 |
|---|---:|---|
| QFL 得分损失受控适配 | 89.8272 | 低于基线 0.8486 点，阴性 |
| 几何对照 power / scaled | 90.3286 / 89.4689 | 均低于基线，阴性 |
| ROI 辅助（GT / 特征） | 90.1289 / 90.3116 | 均低于基线，阴性 |
| 轻量像素学生（四条件） | 最好 90.3358 | 低于基线，不扩种子 |
| 冻结 ROI 小头、全提案检查 | 无完整优势 | 停止 |
| 监督筛选三组、硬目标/普通 KL | 未优于基线 | 未通过 |
| 六组辅助方案复查 | 全部低于 91.09% 普通源 val 基线 | 阴性 |
| LP-FT / FT 冻结头对照（10-26） | B/C 固定框正确率 86.82%/86.93%（LP-FT） | 已有方法基线，不是创新 |

**结论**：截至 2026-11-16，不宣称任何原创方法已经成立。失败记录、停止条件和负结果全部保留，后续按"结果到主张"流程判读，不再盲目扫参。
