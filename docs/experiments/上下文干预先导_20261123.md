## 一、任务

在**固定器官参考框、框内像素逐字节不变**的前提下，只改变框外区域，回答三件事：

1. 框外背景变化会不会改变同一叶片的症状分类？
2. 这种改变是不是"只要动像素就会变"（等面积对照能否复现）？
3. 如果效应可重复，是否值得进入第二阶段（源 train 症状标签的小规模一致性消融）？

## 二、结论摘要

1. **会变，而且不小**：把 testB（田间）的框外替换成 testC（浅色桌面）的真实背景后，常规基线正确数 **486 → 390（−96，−15.9pt）**；反方向 testC → testB 为 **434 → 319（−115，−19.1pt）**。两套模型、两个方向、四种组合方向一致。
2. **不是"动像素就会变"**：只替换与框等面积的一块区域，正确数 **485/602（−1）** 与 **441/602（+7）**，翻转数只有 47 和 39，远小于 D2 的 162 和 205。分类错误增量 D2 是 D3 的 **7.1 倍（testB）/ 4.75 倍（testC）**。
3. **但"真实背景替换"相对既有的"置灰"并没有带来更多分类错误**：由对变"类别错误"的数量 D2=57、D1=53（testB），D2=57、D1=80（testC）。D2 多出来的损害主要是**定位丢失与未输出**（testB：33 定位不足 + 39 未输出；testC：63 + 40）。
4. **因此第二阶段不启动**：预注册判据 A、B 通过，C（D2 翻转集合与 D1 重叠 < 50%）实测 **54.3% / 52.7%**，未通过。按协议停在第一阶段。

**一句话**：框外背景确实参与症状分类，且不是任意扰动所致；但"换成另一种真实背景"额外造成的损失，主要打在检测定位上，而不是分类上。这会改变第二阶段该往哪做。

## 十、能说什么 / 不能说什么

**能说：**

- 在参考框内像素完全不变的条件下，替换框外整片背景会显著改变检测器的症状判定（−12 到 −26 个百分点，两个方向、两套权重一致）。
- 这种改变不是"任意像素扰动"造成的：等面积对照的效应接近 0（−2 到 +3 个百分点），分类错误增量只有 D2 的 1/5 到 1/7。
- 损失可以拆成两半：约 1/3–1/2 是"框还在、类别变了"，其余是"框丢了/没输出"。

**不能说：**

- 不能说这是"独立验证"或"部署性能"：testB/testC 是历史探索集，且参考框来自发布者标注，App 推理拿不到。
- 不能说"背景是因果原因"：替换用的是另一张图的背景，会带来接缝、遮挡和 donor 图里其他叶片；矩形也不是叶片前景掩膜。
- 不能说"改分类器就能解决"：一半以上的损害在定位与输出，不在分类头。
- 不能把 D3 的 +7 / +16 解读为"等面积替换有好处"：量级在噪声附近，且方向不一致。

## 十一、异常与局限

1. D1 置灰把"定位不足"几乎清零（testB 28→1、testC 2→1），与 9 月记录一致；说明灰底让检测器更容易锁定唯一目标，但代价是未输出增加。
2. D2 的 donor 是同序号图像，不是同对象配对；B/C 的文件名无法一一对应，本轮不假设配对。
3. 参考框取整从 `int()` 改为 `floor/ceil`，与历史裁框分类有 1 像素差异；影响 1/30 抽样预测，未影响检测基准（486/485/434/462 逐位一致）。
4. 所有图像 640×480，小病斑信息在采集端已截断。
5. 本实验是单目标口径（每图一个参考框），与多目标 mAP 不是一回事。
