## 九、当前研究判断

### 9.1 已经得到的稳定判断

1. 干净背景同源分类已经接近饱和，继续刷同源 Accuracy 的收益有限。
2. 轻量模型在跨域场景中更容易掉点，ResNet50 在当前 M0 协议下更稳定。
3. DANN 两次单次实验都获得大幅提升，域适应值得作为下一阶段重点。
4. 当前 SimCLR 配置没有超过 ImageNet 初始化，不适合直接作为主要贡献。
5. SciDB 上的简单 YOLOv8n 预训练基线很强，复杂结构必须通过公平实验才能证明价值。
6. Leaf-Only-SAM 对部分病叶分割不稳定，暂时不适合作为无人核验的自动预处理。

### 9.2 目前不能下的结论

1. 不能说 DANN 已经稳定提升 50 个百分点以上，因为还没有多随机种子统计。
2. 不能说作者三通道结构一定无效，因为当前初始化、轮数和模型规模不完全一致。
3. 不能说 SimCLR 对最终胡柚任务无效，因为当前无标签池和目标任务仍然有限。
4. 不能把 CMS 和三通道低保真重建写成原论文的严格复现。
5. 不能把同一验证集上的高精度当成真实田间泛化能力。

## 十、建议的后续顺序

1. 补作者模型混淆矩阵，并将本报告、截图和哈希清单作为当前基准快照。
2. 为 DANN 建立独立目标域验证集和测试集，再运行 3～5 个随机种子。
3. 补源域保持率、目标域 Macro-F1、逐类 F1 和混淆矩阵。
4. 为 SciDB 增加同初始化、同轮数、同早停规则的公平检测对照。
5. 使用缺素和未对齐病害建立最大 Softmax、Energy Score 等开放集拒识基线。
6. 尽快接入胡柚/香柚自采数据，并把独立果园或独立拍摄批次留作最终测试域。
7. 等田间协议和主线稳定后，再做蒸馏、量化和移动端部署。

当前最值得继续的研究主线是：

> **真实田间跨域适应 + 缺素/黄龙病开放集鉴别。**
