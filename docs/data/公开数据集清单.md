# 柑橘公开数据集清单（更新于 2026-08-29）

> 只收**柑橘类**公开数据集（对本课题直接有用）。按角色组织：源域(实验室) / 目标域(真实田间) / 柑橘检测。
> 核实：✓=一手核验；△=需账号；待核=二手/摘要级。

### 已发现但不计入“可下载数据”

- **福建多品种 HLB RGB 集（7,516 张、14 个症状）**：包含椪柑、沃柑/杂柑、砂糖橘、脐橙、温州蜜柑和沙田柚，内容非常贴合；但论文只写“作者可提供”，没有公开文件直链，暂不计入可下载集。论文：https://doi.org/10.3389/fpls.2022.1002606
- **HOCD-4（3,511 张自然果园检测图）**：论文给出的 GitHub 仓库 `AlanPikaso/HOCD-4` 于 2026-08-29 实测为 404，暂不可下载。
- **Roboflow Citrus Greening（500 图）**：公开预览但导出需账号，且缺少采集来源说明，只作低可信候选。
- **YOLO-Citrus（2025）自建数据**：论文只声明原始数据可由作者提供，没有公开文件地址，不计入“已确认可下载”。论文：https://doi.org/10.3389/fpls.2025.1668036
- **Kaggle Citrus Leaf Disease Image（约 43 MB）**：类别与本地 Mendeley 609 张叶片集完全一致，极可能是同源镜像，不作为新增数据。页面：https://www.kaggle.com/datasets/myprojectdictionary/citrus-leaf-disease-image
- **firc-dataset 柑橘病害条目**：GitHub/Gitee 仓库实际仅为外部商业资源索引，未托管数据文件，许可证与图像来源不清，不列入正式候选。

## 优先级（落地胡柚）
1. **福建 SciDB**（田间多类，目标域主力，本地已有）→ 2. **甜橙 5,813 张 RGB 集 `f7cr74mwpj`**（新增分类下载第一优先）→ 3. **CitrusUAT**（HLB 确诊+缺素+虫害，本地已有）→ 4. **柚 868 张真实原图 `vk7dnf8nrj`**（物种域辅助）→ 5. **Zenodo 1,944 张检测集** → 6. **CCL'20 2,684 张检测集** → 7. ABCGMP / Orange-HLB / Kaggle 橙（补充）。
> 检测任务优先新增 Zenodo 1,944 张集和 CCL'20；CitDet/UAV 果检测主要标注“果实”而非“病斑”，主线病害分类暂不优先。Digital Green 的 12 张柑橘图只作为跨域外测。

## 附：非柑橘集（仅方法层备用，不属本清单）
PlantVillage(预训练)、PlantDoc/Corn/Tomato(跨作物域适应对照)、MH-Soya(空地配对模板)、PlantSeg(分割)、PDT(UAV)——**都不是柑橘**，仅在需要预训练或跨作物对照时按需取，不作为本课题数据。
