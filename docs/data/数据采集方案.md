# 常山胡柚 / 香柚 病害数据 · 田间采集方案

> 用途：赴常山田间采集目标品种（香柚 / 胡柚）病害图像，为"跨品种（公开橙橘→胡柚）+ 实验室→田间"的复现与方法落地提供目标域数据。
> 一句话：先把 **健康 + 溃疡** 采扎实，**缺素**采够，**黄龙病只送 PCR**；每片拍单叶+挂枝两版、香柚胡柚各半、分散在十几棵树，起步约 1000–1200 张。

---

## 一、采集目标

### 品种
常山 **香柚 + 胡柚**（两个都采，分开记录）。

### 病种 / 类别（按优先级）

| 优先级 | 类别 | 说明 |
|---|---|---|
| **必采（锚定）** | 健康叶、**溃疡病** | 7 月高发、症状清晰、现场好判，公开集也有——最稳的落点 |
| **尽量采** | 炭疽、**缺素黄化** | 缺素尽量分清类型（缺镁 / 缺锌 / 缺氮…），它最容易和黄龙病混 |
| **不现场判** | 黄龙病（HLB） | 肉眼不可靠、需 PCR；见疑似只**标记 + 记位置 + 采样送检**，绝不凭肉眼当标签 |
| 可选（遇到就采） | 疮痂、黑点、煤烟病、潜叶蛾（虫害） | 7 月能见的，补充 |

---

## 二、数量与分布

### 总量
起步约 **1000–1500 张可用**。按"独立叶片"算约 **500–700 片**，因每片拍**单叶 + 挂枝两版**，张数 ≈ 片数 × 2。

### 分布（起步第一轮）

| 类别 | 叶片数 | 张数（×2 版） | 品种分配 |
|---|---|---|---|
| **健康** | 150 | ~300 | 香柚 / 胡柚各半 |
| **溃疡病** | 150 | ~300 | 各半 |
| **缺素黄化** | 100 | ~200 | 各半；尽量分缺镁 / 缺锌等 |
| 炭疽 | 60 | ~120 | 各半 |
| 其它（疮痂 / 黑点 / 煤烟 / 潜叶蛾） | 遇到就采，共 50–80 | ~100–160 | — |
| 黄龙病疑似 | 10–20（**送 PCR**） | 不计入训练量 | 记位置 |

合计 ≈ **500–560 片 → ~1000–1200 张**（核心）。后续再把每类扩到 200–300 片。

### 分布原则
1. **锚定类（健康 + 溃疡）占大头**——各 150 片，先把这两类采扎实，能先跑通全流程。
2. **缺素要采够（≥100 片）**——治"缺素↔黄龙病混淆"的关键类，别少。
3. **稀有类尽力就好**——炭疽 / 疮痂等 7 月可能偏少，采不到别硬凑（长尾正常，后续靠增广 / 少样本补）。
4. **每类里香柚、胡柚尽量各一半**——课题核心是跨品种，两品种都得有代表性。
5. **每类留 ~20% 当测试集**，且这 20% 尽量来自**没进训练的树 / 地块**，否则评测会虚高。

### 分散度要求
每类的 150 片**别集中在一两棵树上**——尽量覆盖 **10–15 棵不同树 + 多光照 / 多角度**，否则模型学到的是"这棵树 / 这个光照"，换棵树就崩。

---

## 三、采集方法（SOP）

**1. 每片病叶拍"两版"（关键）**
- **① 贴近单叶**：叶片占满画面、对焦病斑，看清细节 → 对齐公开单叶、做分类；
- **② 自然挂枝**：退后拍带枝条 / 背景的自然状态（复杂背景）→ 这版和 ① 的差，就是要研究的"实验室→田间"域差。
- 单叶为主（分类起步）；随手的多叶合影也留几张（以后抠叶 / 检测用）。

**2. 刻意多样化**（否则模型学到的是背景不是病）
- 多光照：晴天 / 阴天、上午 / 中午、顺光 / 逆光；
- 叶**正反面都拍**（溃疡初期、脂点等在背面更明显）；
- 换不同树、不同地块、不同树龄；别对同一片叶狂拍十几张。

**3. 成批采**：一次集中采一类（今天主攻溃疡树，明天健康 + 炭疽），效率高、好归类。

---

## 四、每张要记的信息

拍时或用小表格记录：

> **品种（香柚 / 胡柚）｜ 地点 / 树号 ｜ 日期 ｜ 天气 ｜ 疑似病名 ｜ 叶正 / 反**

- 拿不准的病一律记 **"待确认"**，现场找人判。
- 边采边按 `品种_病名_日期` 建文件夹丢进去，回来省事。

---

## 五、必须避开的坑

1. **黄龙病别自标**——肉眼判的大概率不准，只标记疑似 + 采样送 PCR。
2. **缺素 vs 早期黄龙病极像**——复现实测缺素被大量误判成黄龙病；现场拿不准的黄叶统统标"待确认"，别硬归。
3. **确诊的人提前定**——溃疡 / 炭疽 / 缺素这些，最好现场有**老师 / 农技员 / 植保站**的人帮定病名，这是整套数据能不能用的命门。
4. **背景别太单一**——都在同一堵墙 / 同一块布前拍，等于白采。

---

## 六、果实采集（叶为主线，果为补充）

**要采，但分主次、看季节。** 柚类很多病叶、果都发，有些果实症状更典型、更贴商品价值；公开集（Mendeley 果、CitDet、SciDB 的"红鼻果 / 健康果"）也有果实数据可对齐。

- **本轮（7 月）以叶片为主线**（症状最全、采集方便、与公开单叶对齐），果实**顺带采**；成熟果病害等 **9–11 月果期**再重点采。
- **该采的果实症状**：健康果、**溃疡病果**（果面木栓化、火山口状斑，很典型）、疮痂 / 黑斑（影响商品果外观）、炭疽（果面凹陷腐斑）、黄龙病"**红鼻果**"（青果不转色 / 歪斜——同样只作疑似、送 PCR）。
- **怎么采**：同叶片 SOP——每个果拍**单果特写 + 挂树自然背景**两版，健康果 / 病果都要，记录品种 / 树号 / 疑似病名。7 月多为青果 / 幼果，先采现有果面症状，量不用多（每类几十个即可，秋季再扩）。

---

## 七、分阶段与后续

- **第一轮（本次）**：把 **健康 + 溃疡** 采够（先跑通），**缺素**采够；炭疽和其它遇到就采；黄龙病送 PCR。
- **后续（9–10 月）**：补 **炭疽 / 疮痂**（这季更多），并把各类扩到每类 200–300 片。

## 附 · 确诊安排（最关键，提前落实）
现场请**老师 / 农技员 / 植保站**确认病名（尤其溃疡 vs 疮痂、炭疽、缺素 vs 早期黄龙病）；黄龙病疑似样本采样送 **PCR** 确诊，确诊后才作为标签使用。
